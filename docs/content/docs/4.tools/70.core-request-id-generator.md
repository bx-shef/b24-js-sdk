`RequestIdGenerator`{lang="ts-type"} — реализация `IRequestIdGenerator`{lang="ts-type"} по умолчанию, которую HTTP-клиенты используют, чтобы:

- сгенерировать уникальный идентификатор для каждого исходящего запроса через [`Text.getUuidRfc4122()`](/docs/tools/text/) (UUID v7);
- определить, в каком HTTP-заголовке он передаётся (`X-Request-ID`);
- определить, в каких параметрах строки запроса передаются он и метаданные SDK (`bx24_request_id`, `bx24_sdk_ver`, `bx24_sdk_type`).

Переопределять его нужно только для серверной корреляции с существующей схемой трассировки (например, чтобы передавать идентификатор запроса из вышестоящего сервиса) — реализуйте `IRequestIdGenerator`{lang="ts-type"} и внедрите его через собственную настройку `Http`.

## Константы по умолчанию

| Константа | Значение |
|----|----|
| Поле заголовка | `X-Request-ID` |
| Параметр запроса | `bx24_request_id` |
| Параметр запроса (версия SDK) | `bx24_sdk_ver` |
| Параметр запроса (тип SDK) | `bx24_sdk_type` |

Последние два постоянны для сборки (подставляются при компиляции `unbuild`).

## API

```ts-type
class RequestIdGenerator implements IRequestIdGenerator {
  getRequestId(): string                       // UUID v7
  getHeaderFieldName(): string                 // 'X-Request-ID'
  getQueryStringParameterName(): string        // 'bx24_request_id'
  getQueryStringSdkParameterName(): string     // 'bx24_sdk_ver'
  getQueryStringSdkTypeParameterName(): string // 'bx24_sdk_type'
}
```

## Интерфейс `IRequestIdGenerator`

```ts-type
interface IRequestIdGenerator {
  getRequestId(): string
  getHeaderFieldName(): string
  getQueryStringParameterName(): string
  getQueryStringSdkParameterName(): string
}
```

Если вы передаёте собственную реализацию, убедитесь, что `getRequestId()` возвращает значение, **уникальное для каждого вызова**: по нему ведут учёт лимитер и журнал запросов.
