## Обзор

`Type`{lang="ts-type"} — синглтон (`new TypeManager()`), экспортируемый из `@bxshefby/b24jssdk`. Каждый метод (кроме `getTag` и `clone`) — защита типа TypeScript, поэтому его можно использовать в цепочках `if`, и компилятор сузит тип значения:

```ts
import { Type } from '@bxshefby/b24jssdk'

function process(value: unknown) {
  if (Type.isStringFilled(value)) {
    // value: string
    return value.trim()
  }
  if (Type.isPlainObject(value)) {
    // value: Record<string | number, any>
  }
}
```

Защиты сгруппированы по виду проверяемого значения:

- **Строки** — проверки непустых строк.
- **Числа и булевы значения** — число, целое, дробное, булево.
- **Объекты и функции** — простые объекты, функции, `Map` / `Set` / `WeakMap` / `WeakSet`, `RegExp`, прототипы, `null` / `undefined`.
- **Массивы** — массивы, значения, похожие на массивы, типизированные массивы, `ArrayBuffer`.
- **DOM** — узлы, узлы-элементы, текстовые узлы.
- **Файлы** — `Blob`, `File`, `FormData`.
- **JSON-RPC** — формы сообщений запроса и ответа.
- **Прочее** — `getTag` («сырой» тег `[[Class]]`) и `clone` (глубокое клонирование).

## Сигнатура метода

### Строки

| Метод | Предикат |
|----|----|
| `isString(value)` | `typeof value === 'string'` или `value instanceof String`. |
| `isStringFilled(value)` | `isString(value) && value !== ''`. |

### Числа и булевы значения

| Метод | Предикат |
|----|----|
| `isNumber(value)` | `typeof value === 'number'` и не `NaN`. |
| `isInteger(value)` | `Number.isInteger(value)`. |
| `isFloat(value)` | `isNumber && !isInteger`. |
| `isBoolean(value)` | `value === true \|\| value === false`. |

### Объекты и функции

| Метод | Предикат |
|----|----|
| `isFunction(value)` | `typeof value === 'function'` (также экземпляры `Function`). |
| `isObject(value)` | `typeof === 'object' \|\| 'function'` (и не `null`). |
| `isObjectLike<T>(value)` | только `typeof === 'object'` (также истинно для объектов, не равных `null`, включая массивы). |
| `isPlainObject(value)` | Истинно для объектов, у которых `constructor` равен `Object` (ложно для массивов, экземпляров классов, узлов DOM). |
| `isPrototype(value)` | Истинно для объектов `prototype`. |
| `isMap`, `isSet`, `isWeakMap`, `isWeakSet`, `isRegExp` | Проверки по тегу (`Object.prototype.toString.call(value)`). |
| `isDate(value)` | `value instanceof Date`. |
| `isNil(value)` | `value === null \|\| value === undefined`. |
| `isNull` / `isUndefined` | Не требуют пояснений. |

### Массивы

| Метод | Предикат |
|----|----|
| `isArray(value)` | `Array.isArray`. |
| `isArrayFilled(value)` | `isArray && value.length > 0`. |
| `isArrayLike(value)` | Имеет числовое `length` и не является функцией — подходят и строки. |
| `isArrayBuffer(value)` | Проверка по тегу. |
| `isTypedArray(value)` | Подходит для `Int8Array / Uint8Array / Uint8ClampedArray / Int16Array / Uint16Array / Int32Array / Uint32Array / Float32Array / Float64Array` (проверка по тегу). |

### DOM

| Метод | Предикат |
|----|----|
| `isDomNode(value)` | Имеет `nodeType` и не является простым объектом. |
| `isElementNode(value)` | `nodeType === Node.ELEMENT_NODE`. |
| `isTextNode(value)` | `nodeType === Node.TEXT_NODE`. |

### Файлы, Blob и FormData

| Метод | Предикат |
|----|----|
| `isBlob(value)` | Имеет `size: number`, `type: string`, `slice: Function`. |
| `isFile(value)` | `isBlob && name: string && (lastModified \|\| lastModifiedDate)`. |
| `isFormData(value)` | `instanceof FormData` (если глобальный объект доступен) или проверка по тегу. |

### JSON-RPC

| Метод | Предикат |
|----|----|
| `isJsonRpcRequest(value)` | Имеет `jsonrpc` (непустой) и `method` (непустой). Тип возвращаемого значения — `boolean`, а не защита типа. |
| `isJsonRpcResponse(value)` | Имеет `jsonrpc`, `id` и либо `result`, либо `error`. Тип возвращаемого значения — `boolean`, а не защита типа. |

### Прочее

```ts-type
getTag(value: any): string                          // Object.prototype.toString.call(value)
clone(obj: any, bCopyObj?: boolean): any             // deep clone; bCopyObj defaults to true
```

## Ключевые понятия

- **`isJsonRpcRequest` / `isJsonRpcResponse` — обычные предикаты `boolean`, а не защиты типа.** Каждый другой метод этого класса сужает тип через `value is X`; эти два (намеренно или нет) возвращают `boolean`, поэтому их использование в `if` не сужает тип `value`.
- **`isObjectLike<T>` сужает тип до переданного вызывающей стороной дженерика, а не до `object`.** Он проверяет только `typeof value === 'object' && value !== null`; переданный вами `T` во время выполнения не проверяется — проходят массивы, `Map`, `Date` и узлы DOM. Когда нужен именно объект вида `{}`, строже проверка `isPlainObject`.
- **`isArrayLike` подходит и для строк.** У строк есть числовое `length`, и они не функции, поэтому `Type.isArrayLike('abc')` равно `true`. Когда нужен настоящий массив, используйте `isArray`.
- **`isDomNode` требует настоящего глобального DOM.** `isElementNode` / `isTextNode` обращаются к глобальной константе `Node`, поэтому работают только в браузере (или JSDOM) — вызов в обычном Node.js без DOM-прослойки выбрасывает `ReferenceError`.
- **`clone` ничего не изменяет в источнике, но клонирует только распознаваемые простые формы данных.** Массивы и простые объекты копируются по ключам (рекурсивно, если `bCopyObj` не равен `false`), `Date` пересоздаётся через `new Date(obj)`, а узлы DOM проходят через `Node.cloneNode(bCopyObj)`. Всё остальное с `typeof obj === 'object'` попадает в общую ветку и пересоздаётся через `new obj.constructor()`, поэтому пользовательские классы с обязательными аргументами конструктора могут выбросить исключение.

## Обработка ошибок

Методы-защиты никогда не выбрасывают исключения для проверяемого значения — несовпадающее, `null` или `undefined` просто даёт `false`. Исключения зависят от среды: `isElementNode` / `isTextNode` обращаются к глобальной константе `Node` и выбрасывают `ReferenceError` вне среды DOM, а `clone` может выбросить исключение, когда переходит к `new obj.constructor()` для класса, которому нужны аргументы конструктора. Защищайте такие вызовы при выполнении на сервере или при клонировании произвольных экземпляров классов.

## Примеры

Сужение типа с помощью защит строк и объектов:

```ts
import { Type } from '@bxshefby/b24jssdk'

function describe(value: unknown): string {
  if (Type.isStringFilled(value)) {
    return `string: ${value.trim()}`
  }
  if (Type.isPlainObject(value)) {
    return `object with ${Object.keys(value).length} keys`
  }
  if (Type.isArrayFilled(value)) {
    return `array with ${value.length} items`
  }
  return 'unknown'
}

describe('  hi  ') // 'string: hi'
describe({ a: 1 }) // 'object with 1 keys'
describe([1, 2, 3]) // 'array with 3 items'
```

Проверки по тегу и `getTag`:

```ts
import { Type } from '@bxshefby/b24jssdk'

Type.getTag([1, 2, 3])   // '[object Array]'
Type.getTag(new Map())   // '[object Map]'
Type.getTag(/abc/)       // '[object RegExp]'

Type.isMap(new Map())    // true
Type.isSet(new Set())    // true
Type.isRegExp(/abc/)     // true
```

Формы сообщений JSON-RPC:

```ts
import { Type } from '@bxshefby/b24jssdk'

Type.isJsonRpcRequest({ jsonrpc: '2.0', method: 'ping', id: 1 }) // true
Type.isJsonRpcRequest({ jsonrpc: '2.0' })                         // false, no `method`

Type.isJsonRpcResponse({ jsonrpc: '2.0', id: 1, result: { ok: true } }) // true
Type.isJsonRpcResponse({ jsonrpc: '2.0', id: 1 })                       // false, no `result`/`error`
```

Глубокое клонирование с помощью `clone`:

```ts
import { Type } from '@bxshefby/b24jssdk'

const original = { a: 1, nested: { b: 2 } }

const deep = Type.clone(original)
deep.nested.b = 99
console.log(original.nested.b) // 2 — untouched, deep clone

const shallow = Type.clone(original, false)
shallow.nested.b = 42
console.log(original.nested.b) // 42 — same nested reference, shallow clone
```

## Альтернативы и рекомендации

- **Предпочитайте методы-защиты типа (`value is X`) ручным проверкам `typeof` / `instanceof`.** Читаются они так же, но ещё и сужают тип TypeScript значения внутри ветки `if`, чего не делают две проверки JSON-RPC, возвращающие `boolean`.
- **Используйте `isPlainObject` вместо `isObject`, когда нужна запись вида `{}`.** `isObject` также принимает функции, а `isObjectLike` — массивы, `Map`, `Date` и узлы DOM; `isPlainObject` — единственная из трёх, которая исключает всё это.
- **`isTypedArray` охватывает девять конкретных представлений типизированных массивов, но не `DataView`.** Он подходит для `Int8Array` … `Float64Array`, но возвращает `false` для `DataView`; используйте `ArrayBuffer.isView(value)`, когда нужно включить и `DataView`.
- **Приведение строк и чисел и форматирование находятся в [`Text`](/docs/tools/text/).** `Type` только проверяет формы; когда значение нужно преобразовать, а не просто проверить, используйте `Text.toNumber` / `Text.toInteger` / `Text.toBoolean`.
- **`clone` — универсальное глубокое клонирование, а не замена structured clone.** Для значений, которыми вы управляете (простые данные из REST API), его достаточно; для полезной нагрузки `Map` / `Set` / `ArrayBuffer` или значений, где нужна точность прототипов, используйте `structuredClone` (где он доступен) или специальную библиотеку клонирования.
