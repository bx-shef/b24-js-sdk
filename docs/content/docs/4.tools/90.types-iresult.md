`IResult<T>`{lang="ts-type"} фиксирует шаблон «флаг успеха + данные + набор ошибок», используемый во всём SDK. Конкретные классы:

- [`Result<T>`{lang="ts-type"}](/docs/tools/core-result/) — универсальный.
- [`AjaxResult<T>`{lang="ts-type"}](/docs/tools/core-ajax-result/) — для REST (неизменяемый, постраничный, декодирует конверты ошибок Битрикс24).

::note
**`T` по умолчанию равен `unknown`, а не `any`** (начиная с 3.0.0, #279). Именно указание полезной нагрузки делает остальное чтение типобезопасным — каждое действие принимает дженерик (`call.make<T>`, `batch.make<T>`, `callList.make<T>`). Чтение поля у неуточнённого `Result`{lang="ts-type"} — ошибка компиляции, в этом и смысл.
::

## Форма

```ts-type
interface IResult<T = unknown> {
  readonly isSuccess: boolean
  readonly errors: Map<string, Error>

  setData(data: T | null | undefined): IResult<T>
  getData(): T | null | undefined

  addError(error: Error | string, key?: string): IResult<T>
  addErrors(errors: (Error | string)[]): IResult<T>
  getErrors(): IterableIterator<Error>
  getErrorMessages(): string[]
  getErrorsByKey(): Record<string, Error>
  getErrorMessagesByKey(): Record<string, string>
  hasError(key: string): boolean

  toString(): string
}
```

Каждый изменяющий метод возвращает сам результат, параметризованный тем же `T`{lang="ts-type"}, поэтому цепочка сохраняет тип полезной нагрузки. До v2.2.0 `addError` / `addErrors` объявлялись как возвращающие «голый» `IResult`{lang="ts-type"} (то есть `IResult<any>`{lang="ts-type"}), что молча понижало `getData()` до `any`{lang="ts-type"} для всего, что читалось после вызова в цепочке.

`AjaxResult<T>`{lang="ts-type"} сужает `setData` до `never` (неизменяемый ответ) и переопределяет `getData()`, чтобы при `isSuccess` возвращать [`SuccessPayload<T>`{lang="ts-type"}](https://github.com/bx-shef/b24-js-sdk/blob/main/packages/jssdk/src/types/payloads.ts).

## Типичный порядок использования

```ts
import type { IResult } from '@bxshefby/b24jssdk'

function consume<T>(result: IResult<T>) {
  if (!result.isSuccess) {
    for (const message of result.getErrorMessages()) {
      console.error(message)
    }
    return
  }
  const data = result.getData()
  // ...
}
```
