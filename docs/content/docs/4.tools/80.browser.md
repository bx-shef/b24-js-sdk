## Обзор

`Browser`{lang="ts-type"} — синглтон (`new BrowserManager()`), экспортируемый из `@bxshefby/b24jssdk`. Он объединяет простые проверки user-agent, платформы и возможностей, на которые SDK опирается внутри, и предоставляет их коду приложения:

- **Определение браузера** — Opera, Internet Explorer (с 6 по 11, а также числовой `detectIEVersion`), Safari, Firefox, Chrome.
- **Определение ОС и платформы** — macOS, Windows, Linux, Android (с `detectAndroidVersion`), iPad, iPhone и сводный `isIOS`.
- **Возможности** — `isMobile`, `isRetina`, `isTouchDevice`, `isDoctype` и `isLocalStorageSupported`.

Все проверки выводятся из строки `UA` уровня модуля — `navigator.userAgent` в нижнем регистре, захваченного один раз при импорте, — или из глобальных объектов браузера (`window`, `document`, `navigator`, `localStorage`). Поэтому `Browser` имеет смысл только в контексте браузера.

```ts
import { Browser } from '@bxshefby/b24jssdk'

if (Browser.isMobile()) {
  // ...
}

if (Browser.isLocalStorageSupported()) {
  // ...
}
```

## Сигнатура метода

### Определение браузера

```ts-type
isOpera(): boolean                           // UA includes 'opera'
isIE(): boolean                              // legacy 'attachEvent' in document, and not Opera
isIE6(): boolean                             // UA includes 'msie 6'
isIE7(): boolean                             // UA includes 'msie 7'
isIE8(): boolean                             // UA includes 'msie 8'
isIE9(): boolean                             // document.documentMode >= 9
isIE10(): boolean                            // document.documentMode >= 10
isIE11(): boolean                            // detectIEVersion() >= 11
detectIEVersion(): number                    // numeric IE version, -1 if not IE
isSafari(): boolean                          // UA includes 'safari' and not 'chrome'
isFirefox(): boolean                         // UA includes 'firefox'
isChrome(): boolean                          // UA includes 'chrome'
```

### Определение ОС и платформы

```ts-type
isMac(): boolean                             // UA includes 'macintosh'
isWin(): boolean                             // UA includes 'windows'
isLinux(): boolean                           // UA includes 'linux', and not Android
isAndroid(): boolean                         // UA includes 'android'
detectAndroidVersion(): number               // parsed Android version, 0 if not detected
isIPad(): boolean                            // UA includes 'ipad;', or Mac + touch
isIPhone(): boolean                          // UA includes 'iphone;'
isIOS(): boolean                             // isIPad() || isIPhone()
```

### Возможности

```ts-type
isMobile(): boolean                          // iPhone / iPad / Android / 'mobile' / 'touch' UA
isRetina(): boolean                          // window.devicePixelRatio >= 2
isTouchDevice(): boolean                     // 'ontouchstart' in window, or maxTouchPoints > 0
isDoctype(target?: any): boolean             // compatMode === 'CSS1Compat' (or fallback)
isLocalStorageSupported(): boolean           // setItem/removeItem round-trip succeeds
```

## Ключевые понятия

::note
`Browser` читает `navigator.userAgent` в переменную уровня модуля `UA` **один раз**, при импорте. Чтение обёрнуто в `try`/`catch`, поэтому импорт модуля вне браузера (например, Node/SSR) не выбрасывает исключение — `UA` просто принимает значение `'?'`, и каждая проверка по UA возвращает `false`. Методы, которые обращаются к `window`, `document` или `localStorage` напрямую (`isRetina`, `isTouchDevice`, `isDoctype`, `isLocalStorageSupported`, `isIE`/`isIE9`/`isIE10`), по-прежнему предполагают существование этих глобальных объектов, поэтому их вызов вне браузера может выбросить исключение.
::

::caution
Это определение по user-agent, а не по возможностям. Строки user-agent можно подделать или оставить пустыми, а браузеры всё чаще замораживают и сокращают сведения об UA. По возможности отдавайте предпочтение определению возможностей (например, проверке нужного вам API) и считайте `Browser` эвристикой «по мере возможности» для косметических и UX-ветвлений, а не границей безопасности или корректности.
::

- **`isIPad()` охватывает современный iPadOS.** Поскольку iPadOS называет себя macOS в строке UA, `isIPad()` также возвращает `true` для UA в стиле Mac, который к тому же сообщает о поддержке касаний (`isTouchDevice()`), — так он отличает iPad от настоящего настольного Mac.
- **`detectIEVersion()` возвращает `-1` для браузеров, отличных от IE.** Перед запуском эвристик IE/Trident он сразу возвращает `-1` для Opera, Safari, Firefox и Chrome, поэтому его безопасно вызывать безусловно.
- **`isDoctype(target?)` принимает любой объект, похожий на документ.** Передайте `document` iframe (или подобный), чтобы проверить *его* режим отображения, а не страницы верхнего уровня; если опустить `target`, используется глобальный `document`.
- **`isLocalStorageSupported()` — настоящая проверка записи и удаления**, а не просто `typeof localStorage`: она также ловит случаи, когда API есть, но выбрасывает исключение (режимы приватного просмотра, исчерпанная квота хранилища, отключение политикой).

## Обработка ошибок

`Browser` рассчитан на браузерные среды выполнения. Чтение user-agent на уровне модуля и `isLocalStorageSupported()` обёрнуты в `try/catch`, но большинство проверок обращаются к `document` / `window` / `navigator` напрямую (например, `isIE`, `isIE9`, `isRetina`, `isTouchDevice`, `detectIEVersion`, `detectAndroidVersion`) и выбрасывают `ReferenceError`, когда этих глобальных объектов нет. Защищайте любой вызов проверкой среды (или вовсе не используйте `Browser`) в ветках кода Node.js / SSR, которые могут выполняться до гидратации.

## Примеры

Определение браузера:

```ts
import { Browser } from '@bxshefby/b24jssdk'

if (Browser.isChrome()) {
  // Chrome-specific behaviour
}

if (Browser.isIE()) {
  const version = Browser.detectIEVersion()
  console.log(`Running on Internet Explorer ${version}`)
}
```

Ветвление по ОС и платформе:

```ts
import { Browser } from '@bxshefby/b24jssdk'

if (Browser.isIOS()) {
  // Shared iPhone / iPad branch
}

if (Browser.isAndroid()) {
  const version = Browser.detectAndroidVersion()
  console.log(`Android version: ${version}`)
}
```

Проверка возможностей:

```ts
import { Browser } from '@bxshefby/b24jssdk'

if (Browser.isMobile() && Browser.isTouchDevice()) {
  // Adjust layout / hit-targets for touch
}

if (Browser.isRetina()) {
  // Serve high-resolution assets
}
```

Защита доступа к `localStorage` и проверка режима отображения документа:

```ts
import { Browser } from '@bxshefby/b24jssdk'

function persist(key: string, value: string): void {
  if (!Browser.isLocalStorageSupported()) {
    return
  }

  localStorage.setItem(key, value)
}

if (!Browser.isDoctype(document)) {
  console.warn('Page is rendered in quirks mode')
}
```

## Размер прокрутки

Помимо `Browser`, в `src/tools/` есть небольшой помощник `scroll-size`, который сообщает прокручиваемые размеры текущего документа — максимум из `scrollWidth`/`offsetWidth` и `scrollHeight`/`offsetHeight` для `document.documentElement`:

```ts-type
// backing util — packages/jssdk/src/tools/scroll-size.ts
useScrollSize(): { scrollWidth: number, scrollHeight: number }
```

::note
Помощник — `default`-экспорт `tools/scroll-size.ts`, поэтому он **не** реэкспортируется как именованный символ из `@bxshefby/b24jssdk`: `export *` в барреле не пробрасывает экспорты по умолчанию. Читайте эти значения через API фрейма. Он обращается к `document.documentElement`, поэтому работает только в браузерном контексте.
::

Внутри встроенного приложения именно эту утилиту предоставляет [`B24Frame.parent.getScrollSize()`](/docs/entry-points/frame-parent/):

```ts
// $b24 is a B24Frame instance
const { scrollWidth, scrollHeight } = $b24.parent.getScrollSize()
console.log(scrollWidth, scrollHeight)
```

## Альтернативы и рекомендации

- **По возможности отдавайте предпочтение определению возможностей, а не определению по UA.** Проверки `Browser` — эвристики на основе `navigator.userAgent`, который можно подделать, заморозить или сократить в браузере. Например, лучше напрямую проверять `'ontouchstart' in window` (или `Browser.isTouchDevice()`, который делает именно это), чем выводить поддержку касаний из проверок платформы.
- **Используйте `isMobile()` / `isTouchDevice()` для решений о раскладке, а не для ограничения функциональности.** Считайте их подсказками для UX (например, более крупные цели касания, упрощённая навигация), а не способом полностью отключать функции: настольный браузер на ноутбуке с сенсорным экраном — вполне законное сочетание.
- **Методы, связанные с IE (`isIE*`, `detectIEVersion`, `isIE11`), нацелены на давно ушедшие браузеры.** Оставляйте их только для веток обратной совместимости; новому коду, ориентированному на современные браузеры, они обычно не нужны.
- **Проверки типов значений (не среды) находятся в [`Type`](/docs/tools/type/).** `Browser` отвечает на вопрос «в чём я запущен», а `Type` — «какую форму имеет это значение».
