`TypeB24`{lang="ts-type"} — единый тип, который реализуют `B24Frame`{lang="ts-type"}, `B24Hook`{lang="ts-type"} и `B24OAuth`{lang="ts-type"}. Используйте его как тип параметра, когда вашему коду не важно, с каким транспортом он работает.

```ts
import type { TypeB24 } from '@bxshefby/b24jssdk'

async function listAdminTasks($b24: TypeB24): Promise<unknown[]> {
  const response = await $b24.actions.v2.callList.make<{ id: number, title: string }>({
    method: 'tasks.task.list',
    params: { filter: { '!=STATUS': '5' }, select: ['ID', 'TITLE'] },
    idKey: 'id', // задачи возвращают id в нижнем регистре
    cursorIdKey: 'ID', // ...а сортируют и фильтруют по ID в верхнем регистре
    customKeyForResult: 'tasks',
    requestId: 'admin-tasks'
  })
  return response.isSuccess ? response.getData()! : []
}
```

## Форма

```ts-type
type TypeB24 = {
  readonly isInit: boolean
  init(): Promise<void>
  destroy(): void

  getLogger(): LoggerInterface
  setLogger(logger: LoggerInterface): void

  get auth(): AuthActions
  get actions(): ActionsManager
  get tools(): ToolsManager

  setRestrictionManagerParams(params: RestrictionParams): Promise<void>

  getTargetOrigin(): string
  getTargetOriginWithPath(): Map<ApiVersion, string>

  getHttpClient(version: ApiVersion): TypeHttp
  setHttpClient(version: ApiVersion, client: TypeHttp): void
}
```

::note
**Пять членов покинули этот интерфейс в 3.0.0.** `callMethod`, `callListMethod`, `fetchListMethod`, `callBatch` и `callBatchByChunk` были сокращениями, игнорировавшими разделение `restApi:v2` / `restApi:v3`; их заменяют `actions.v{2,3}.{call,callList,fetchList,batch,batchByChunk}.make(options)`. Четыре из пяти заменяются механически; `callListMethod` — нет, см. [руководство по миграции](/docs/getting-started/migration/v3/#calllistmethod-замена-не-один-в-один).
::

## Связанные типы

- [`AuthActions`](https://github.com/bx-shef/b24-js-sdk/blob/main/packages/jssdk/src/types/auth.ts) — возвращается свойством `auth`.
- [`ActionsManager`](https://github.com/bx-shef/b24-js-sdk/blob/main/packages/jssdk/src/core/actions/manager.ts) — возвращается свойством `actions`. Содержит `v2.*` и `v3.*`.
- [`ToolsManager`](https://github.com/bx-shef/b24-js-sdk/blob/main/packages/jssdk/src/core/tools/manager.ts) — возвращается свойством `tools`. Содержит `healthCheck` и `ping`.
- [`TypeHttp`](/docs/tools/core-http/) — возвращается методом `getHttpClient(version)`.
- [`RestrictionParams`](/docs/tools/limiters/) — аргумент `setRestrictionManagerParams`.
- [`ApiVersion`](https://github.com/bx-shef/b24-js-sdk/blob/main/packages/jssdk/src/types/b24.ts) — `'v2'` или `'v3'`.
