Действия — это методы `$b24.actions.v2.*` и `$b24.actions.v3.*`, общие для всех [точек входа](/docs/entry-points/) (`B24Frame`, `B24Hook`, `B24OAuth`). Выберите версию REST API переключателем `restApi:v2 | restApi:v3` в шапке сайта — страницы покажут соответствующие примеры.

::note
Не знаете, какое действие нужно? Начните с руководства [Выбор подходящего метода](/docs/actions/choosing-the-right-method/).
::
