## Добавление в проект

::steps{level="3"}

### Подключите библиотеку

Библиотеку можно подключить напрямую через CDN. Добавьте в HTML-файл такой тег `<script>`:

```html
<script src="https://unpkg.com/@bxshefby/b24jssdk@3/dist/umd/index.min.js"></script>
```
::warning
**Фиксируйте мажорную версию и никогда не используйте `@latest`.** У тега `<script>` нет lock-файла,
поэтому `@latest` переводит приложение на новую мажорную версию сразу после её выхода — вместе
с несовместимыми изменениями и без компилятора, который на них укажет. Когда вышла 3.0.0,
страницы, загружавшие `@latest`, сломались на удалённом `B24Js.LoggerBrowser`
([#586](https://github.com/bitrix24/b24jssdk/issues/586)).
`@3` по-прежнему получает все исправления 3.x. Чтобы остаться на ветке 2.x на время миграции, загружайте
`@2` и смотрите [миграцию на v3](/docs/getting-started/migration/v3/).
::

При необходимости скачайте UMD-версию библиотеки с [unpkg.com](https://unpkg.com/browse/@bxshefby/b24jssdk@3/dist/) и добавьте в проект.

Затем подключите её в HTML-файле:

```html
<script src="/path/to/umd/index.min.js"></script>
```

::note
Сборка `UMD` **включает** свои зависимости (`axios`, `luxon`, `qs-esm`) внутрь, чтобы работать из одного `<script>` без разрешения модулей. Поэтому `npm audit` в вашем проекте **не видит** эти встроенные копии: уязвимость, например, в `axios` попадёт в сборку только с новым выпуском SDK. Для аудита и дедупликации зависимостей используйте входы `ESM` / `CommonJS` (`import` / `require`), в которых зависимости остаются внешними. `UMD` нужен только для прямого подключения через `<script>` / CDN в браузере.
::

### Импорт

После подключения библиотека доступна через глобальную переменную `B24Js`.

```js
B24Js.LoggerFactory.createForBrowser('B24/jsSdk::umd', true);
```

### Инициализация

:::tabs

::::tabs-item{label="B24Frame"}

Чтобы работать с Битрикс24 из приложения, встроенного в интерфейс Битрикс24, используйте объект `B24Frame`.

Он инициализируется на стороне клиента с помощью `initializeB24Frame()`.

```js
const logger = B24Js.LoggerFactory.createForBrowser('B24/jsSdk::umd', true);

try {
  // Initialize B24Frame instance
  let b24 = await B24Js.initializeB24Frame();
  
} catch (error) {
  logger.error('Some problems', { error })
}
```

## Примеры

### B24Frame :badge{label="client-side" class="align-text-top"}

Простой пример получения списка записей: компании через `restApi:v2` и задачи через `restApi:v3`, так как `crm.*` есть только в v2.

::note{color="air-secondary" icon-name="Bitrix24Icon" to="https://apidocs.bitrix24.com/local-integrations/serverside-local-app-with-ui.html"}
Код рассчитан на запуск в пользовательском интерфейсе Битрикс24.
::

::rest-api-version-only
#rest-api-ver2
```html  [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bitrix24 JS SDK Demo</title>
</head>
<body>
<h1>Company Loader Example</h1>
<p>Check developer console for results</p>

<script src="https://unpkg.com/@bxshefby/b24jssdk@3/dist/umd/index.min.js"></script>
<script>
  // Create logger
  const logger = B24Js.LoggerFactory.createForBrowser('B24/jsSdk::umd', true);

  /**
   * Load company list
   */
  async function loadCompanies(b24) {
    try {
      logger.debug('Loading companies...');

      const response = await b24.actions.v2.call.make({
        method: 'crm.item.list',
        params: {
          entityTypeId: B24Js.EnumCrmEntityTypeId.company,
          order: { id: 'desc' },
          select: ['id', 'title', 'createdTime']
        }
      });

      const data = response.getData().result;

      const companies = (data?.items || []).map((item) => {
        return {
          id: Number.parseInt(item.id),
          title: item.title,
          createdTime: B24Js.Text.toDateTime(item.createdTime) // @memo this is luxon/DateTime
        };
      });

      logger.debug('Companies loaded successfully', { companies });
      return companies;
    } catch (error) {
      logger.error('Request failed', { error });
      throw error;
    }
  }

  /**
   * Main application function
   */
  async function main() {
    try {
      // Initialize B24Frame instance
      let b24 = await B24Js.initializeB24Frame();

      // Load companies
      const companies = await loadCompanies(b24);

      // Further data processing...
      logger.info('Loaded ' + companies.length + ' companies');
    } catch (error) {
      logger.error('Some problems', { error })
    }
  }

  /// Start application after DOM load
  document.addEventListener('DOMContentLoaded', function() {
    main();
  });
</script>
</body>
</html>
```

### Текущий пользователь и встройка :badge{label="client-side" class="align-text-top"}

Минимальная страница во фрейме, которая показывает, кто открыл приложение и где оно встроено. Данные встройки (placement) приходят вместе с данными инициализации фрейма, поэтому отдельный запрос не нужен; пользователь берётся из REST-метода `user.current`.

::note{color="air-secondary" icon-name="Bitrix24Icon" to="https://apidocs.bitrix24.com/api-reference/user/user-current.html"}
Код рассчитан на запуск в пользовательском интерфейсе Битрикс24: в слайдере приложения или в зарегистрированной встройке. Для `user.current` нужна область доступа `user_brief` (подходят также `user` и `user_basic`); без неё вызов завершается ошибкой `insufficient_scope`. Если достаточно ID пользователя и признака администратора, методу `profile` нужна только область `basic`.
::

```html [index.html]
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>B24 UMD: user and placement</title>
</head>
<body>
<pre id="out">Loading…</pre>

<script src="https://unpkg.com/@bxshefby/b24jssdk@3/dist/umd/index.min.js"></script>
<script>
  const logger = B24Js.LoggerFactory.createForBrowser('umd-demo', true);
  const out = document.getElementById('out');

  async function main() {
    // 1. Initialize the frame
    const b24 = await B24Js.initializeB24Frame();
    b24.setLogger(B24Js.LoggerFactory.createForBrowser('Core'));

    // 2. Placement: delivered with the init data, no request needed
    const placement = {
      code: b24.placement.placement,        // 'DEFAULT', 'CRM_DEAL_DETAIL_TAB', ...
      isDefault: b24.placement.isDefault,
      isSliderMode: b24.placement.isSliderMode,
      options: b24.placement.options        // PLACEMENT_OPTIONS, e.g. { ID: '123' } on a CRM card
    };

    // 3. Current user: the user.current REST method
    const response = await b24.actions.v2.call.make({ method: 'user.current', params: {} });
    if (!response.isSuccess) {
      throw new Error(response.getErrorMessages().join('; '));
    }
    const u = response.getData().result;

    const info = {
      portal: b24.getTargetOrigin(),
      lang: b24.getLang(),
      isAdmin: b24.auth.isAdmin,
      user: { id: Number(u.ID), name: u.NAME, lastName: u.LAST_NAME, email: u.EMAIL },
      placement
    };

    logger.info('Frame info', info);
    out.textContent = JSON.stringify(info, null, 2);
  }

  document.addEventListener('DOMContentLoaded', () => {
    main().catch((error) => {
      logger.error('Init failed', { error });
      out.textContent = 'Error: ' + (error?.message || error);
    });
  });
</script>
</body>
</html>
```

`b24.placement.options` всегда объект. Регистр его ключей определяет портал, поэтому проверяйте значение, а не полагайтесь на конкретный ключ; см. [Встройка (Placement)](/docs/entry-points/frame-placement/). Токены доступны через `b24.auth.getAuthData()`; пример намеренно их не выводит.
