## Добавление в проект на Nuxt

Чтобы использовать **JS SDK Битрикс24** в проекте на **Nuxt**, подключите модуль `@bxshefby/b24jssdk-nuxt`.

::note
Требуется **Nuxt 4**. Перед началом обновите проект до Nuxt 4.
::

::steps{level="3"}

### Установите пакет JS SDK Битрикс24

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @bxshefby/b24jssdk-nuxt
```

```bash [yarn]
yarn add @bxshefby/b24jssdk-nuxt
```

```bash [npm]
npm install @bxshefby/b24jssdk-nuxt
```

```bash [bun]
bun add @bxshefby/b24jssdk-nuxt
```

::

### Добавьте модуль JS SDK Битрикс24 в `nuxt.config.ts`{lang="ts-type"}

<!-- @check-ignore: defineNuxtConfig is a Nuxt auto-import, not available in SDK typecheck context -->
```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@bxshefby/b24jssdk-nuxt']
})
```

### Импорт

Импортируйте библиотеку в проект:

```ts
import { LoggerFactory } from '@bxshefby/b24jssdk'
```

### Инициализация

:::tabs

::::tabs-item{label="B24Frame"}

Чтобы работать с Битрикс24 из приложения, встроенного в интерфейс Битрикс24, используйте объект `B24Frame`.

Он инициализируется на стороне клиента с помощью `initializeB24Frame()`.

```vue  [SomePage.vue]
<script setup lang="ts">
import type { LoggerFactory, B24Frame } from '@bxshefby/b24jssdk'
import { onMounted, onUnmounted } from 'vue'

const $logger = LoggerFactory.createForBrowser('B24/jsSdk::vue', true)
let $b24: undefined | B24Frame

async function someFunction(): Promise<void> {
  if (!$b24) {
    return
  }
  // ...
}

onMounted(async () => {
  try {
    $b24 = await initializeB24Frame()
  } catch (error) {
    $logger.error('Some problems', { error })
  }
})

onUnmounted(() => {
  $b24?.destroy()
})
</script>
```

::::

::::tabs-item{label="B24Hook"}

::caution{title="⚠️ БЕЗОПАСНОСТЬ"}
Объект `B24Hook` предназначен **только для использования на сервере**.
- Вебхук содержит секретный ключ доступа, который **НЕЛЬЗЯ** использовать в клиентском коде (браузер, мобильное приложение).
- На стороне клиента используйте [`B24Frame`]
::

Чтобы работать с Битрикс24 из отдельного серверного приложения, используйте объект `B24Hook`.

```ts
import { B24Hook } from '@bxshefby/b24jssdk'

// 1. Получите адрес вебхука в Битрикс24:
//    - Откройте Битрикс24
//    - Настройки → Разработчикам → Вебхуки
//    - Создайте новый вебхук с нужными правами
//    - Скопируйте адрес вида: https://your-domain.bitrix24.com/rest/1/your-token/

// 2. Инициализируйте B24Hook
const $b24 = B24Hook.fromWebhookUrl('https://your-domain.bitrix24.com/rest/1/your-token/')

// 3. Вызывайте методы API
```

::::tabs-item{label="B24OAuth"}

::caution{title="⚠️ БЕЗОПАСНОСТЬ"}
Объект `B24OAuth` предназначен **только для использования на сервере**.
- B24OAuth содержит секретный ключ доступа, который **НЕЛЬЗЯ** использовать в клиентском коде (браузер, мобильное приложение).
- На стороне клиента используйте [`B24Frame`]
::

Чтобы работать с Битрикс24 из отдельного серверного приложения, используйте объект `B24OAuth`.

```ts
import { B24OAuth } from '@bxshefby/b24jssdk'

// 1. Зарегистрируйте приложение в Битрикс24:
//    - Откройте Битрикс24
//    - Настройки → Разработчикам → Приложения
//    - Создайте новое приложение
//    - Получите Client ID и Client Secret

// 2. Инициализируйте B24OAuth — данные токена и учётные данные OAuth передаются отдельно.
//    Полная форма B24OAuthParams — в /docs/entry-points/oauth/.
import { EnumAppStatus } from '@bxshefby/b24jssdk'

const $b24 = new B24OAuth(
  {
    applicationToken: 'current_application_token',
    userId: 1,
    memberId: 'portal_member_id',
    accessToken: 'current_access_token',
    refreshToken: 'refresh_token',
    expires: 1745997853, // unix-время, секунды
    expiresIn: 3600,
    scope: 'crm,user_brief',
    domain: 'your-domain.bitrix24.com',
    clientEndpoint: 'https://your-domain.bitrix24.com/rest/',
    serverEndpoint: 'https://oauth.bitrix.info/rest/',
    status: EnumAppStatus.Free
  },
  {
    clientId: 'your_client_id',
    clientSecret: 'your_client_secret'
  }
)

// 3. Вызывайте методы API

// B24OAuth сам обновляет токены, когда истекает их срок
```
