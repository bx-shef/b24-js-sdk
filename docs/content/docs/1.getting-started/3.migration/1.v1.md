В руководстве по шагам описано, как перевести приложение на Bitrix24 JS SDK v1.

::note
Мы старались сохранить совместимость. Если возникнут проблемы, [сообщите нам](https://github.com/bitrix24/b24jssdk/issues).
::

После перехода на Bitrix24 JS SDK v1 учтите следующие важные изменения:

## Изменено

### PlacementManager.title

Чтобы привести свойство в соответствие с документацией и избежать путаницы, `PlacementManager.title` переименовано в `PlacementManager.placement`.

```diff
- if (b24Frame.placement.title === 'DEFAULT') {
+ if (b24Frame.placement.placement === 'DEFAULT') {
  // some code
} 
```

### TypeB24.getTargetOriginWithPath

> Возвращает адрес портала Битрикс24 с путём

Функция теперь возвращает пути для `restApi:v2` и `restApi:v3`.

```diff
+ import { ApiVersion } from '@bxshefby/b24jssdk'

- b24.getTargetOriginWithPath()
+ b24.getTargetOriginWithPath().get(ApiVersion.v2)
+ b24.getTargetOriginWithPath().get(ApiVersion.v3)
```

### TypeB24.getHttpClient

> Возвращает HTTP-клиент для выполнения запроса.

Функция теперь возвращает HTTP-клиент для `restApi:v2` и `restApi:v3`.

```diff
+ import { ApiVersion } from '@bxshefby/b24jssdk'

- b24.getHttpClient()
+ b24.getHttpClient(ApiVersion.v2)
+ b24.getHttpClient(ApiVersion.v3)
```

### Error

Все ошибки теперь наследуются от `SdkError`{lang="ts-type"}. Учитывайте это.

```diff
+ import { SdkError } from '@bxshefby/b24jssdk'

try {
  // ...
} catch (error) {
-  if (error instanceof Error) {
+  if (error instanceof SdkError) {
   // ...
  }
}
```

## Удалено

### Неиспользуемые методы в TypeHttp

Методы регистрации запросов:

* `TypeHttp.setLogTag()`{lang="ts-type"}
* `TypeHttp.clearLogTag()`{lang="ts-type"}

Для этих целей теперь используйте параметр `requestId`.

### Неиспользуемые методы в Http

Метод вывода системных сообщений `Http.getSystemLogger()`{lang="ts-type"}

Теперь принудительный вывод выполняется через [`LoggerFactory.forcedLog()`{lang="ts-type"}](/docs/tools/logger/)

### Restriction Manager

Класс `RestrictionManager` удалён. Вместо него используется система [`Limiters`](/docs/tools/limiters/).

```diff
- import { RestrictionManagerParamsForEnterprise } from '@bxshefby/b24jssdk'
+ import { ParamsFactory } from '@bxshefby/b24jssdk'

- $b24.getHttpClient().setRestrictionManagerParams( RestrictionManagerParamsForEnterprise )
+ $b24.setRestrictionManagerParams( ParamsFactory.getEnterprise() )
// or
+ const b24 = B24Hook.fromWebhookUrl(hookPath, { restrictionParams: ParamsFactory.getEnterprise() })

- $b24.getHttpClient().setRestrictionManagerParams( { sleep: 600, speed: 0.01, amount: 30 * 5 } )
+ $b24.setRestrictionManagerParams( { rateLimit: { burstLimit: 250, drainRate: 5 } } )
```

## Устарело

### AbstractB24.batchSize

> Максимальная длина ответа пакетного запроса (batch).

Эта константа устарела и будет удалена в версии `3.0.0`.

```diff
- if (size < AbstractB24.batchSize) {
+ if (size < 50) {
  // some code ...
}
```

### TypeB24.callMethod

> Вызывает метод REST API Битрикс24.

Этот метод устарел и будет удалён в версии `3.0.0`.

::tabs{class="mt-0"}

:::tabs-item{label="restApi:v2"}

Для `restApi:v2` используйте метод [`b24.actions.v2.call.make(options)`{lang="ts-type"}](/docs/actions/call/).

```diff
- await b24.callMethod('some.method', { filter: { '>id': 123 } }, 100)
+ await b24.actions.v2.call.make({
+   method: 'some.method',
+   params: {
+     filter: { '>id': 123 },
+     start: 100
+   },
+   requestId: 'unique-request-id'
+ })
```

:::

:::tabs-item{label="restApi:v3"}

Для `restApi:v3` используйте метод [`b24.actions.v3.call.make(options)`{lang="ts-type"}](/docs/actions/call/).

<!-- @check-ignore: `some.method` is a placeholder, not a portal method -->
```diff
- await b24.callMethod('some.method', { filter: { '>id': 123 } }, 100)
+ await b24.actions.v3.call.make({
+   method: 'some.method',
+   params: {
+     filter: [['id', '>', 123 ]],
+     pagination: { limit: 50, page: 2 }
+   },
+   requestId: 'unique-request-id'
+ })
```

:::

### LoggerBrowser

> Используется для логирования данных

Этот класс устарел и будет удалён в версии `3.0.0`.

Теперь используется более [универсальная система логирования](/docs/tools/logger/), похожая на [`Monolog (PHP)`](https://github.com/Seldaek/monolog).  

```diff
- import { LoggerBrowser } from '@bxshefby/b24jssdk'
+ import { LoggerFactory } from '@bxshefby/b24jssdk'

- const $logger = LoggerBrowser.build('MyApp', import.meta.env?.DEV === true)
+ const $logger = LoggerFactory.createForBrowser('MyApp', import.meta.env?.DEV === true)

const dataList = { key1: value1, key2: value2 }

- $logger.info('response', dataList)
+ $logger.info('response', { someInfo: dataList })
```
