## Что такое LLMs.txt

LLMs.txt — структурированный формат документации, созданный специально для больших языковых моделей (LLM). JS SDK Битрикс24 публикует файлы LLMs.txt с подробной информацией о библиотеке, чтобы AI-инструменты лучше понимали SDK и помогали в разработке.

Эти файлы оптимизированы для AI и содержат структурированные сведения о компонентах, API, сценариях использования и лучших практиках.

## Доступные маршруты

Документацию для AI-инструментов отдают такие маршруты LLMs.txt:

- **`/llms.txt`** — структурированный обзор всех компонентов со ссылками на документацию (~5 тыс. токенов)
- **`/llms-full.txt`** — полная документация: детали реализации, примеры, темизация, композабл-функции и руководства по миграции (~1 млн токенов и больше)

## Какой файл выбрать

::note
**Большинству пользователей достаточно `/llms.txt`**: в нём есть вся основная информация, и он помещается в стандартное контекстное окно LLM.

`/llms-full.txt` нужен, только если вам требуются подробные примеры реализации и ваш AI-инструмент работает с большим контекстом (200 тыс. токенов и больше).
::

## Важные замечания

::warning
**Символ @ нужно вводить вручную.** В Cursor и Windsurf набирайте `@` в чате руками. При копировании и вставке инструмент не распознаёт его как ссылку на контекст.
::

## Использование с AI-инструментами

### Cursor

JS SDK Битрикс24 публикует специальные файлы LLMs.txt, на которые можно сослаться в Cursor, чтобы AI лучше помогал в разработке.

#### Как использовать:

1. **Прямая ссылка**: укажите URL файлов LLMs.txt в вопросе
2. Добавьте эти URL в контекст проекта через `@docs`

[Подробнее о веб-поиске и поиске по документации в Cursor](https://docs.cursor.com/en/context/@-symbols/@-docs)

### Windsurf

Windsurf может напрямую обращаться к файлам LLMs.txt JS SDK Битрикс24, чтобы разобраться в использовании компонентов и лучших практиках.

#### Использование LLMs.txt в Windsurf:

- Используйте `@docs`, чтобы сослаться на нужные URL LLMs.txt
- Создайте в рабочей области постоянные правила со ссылками на эти URL

[Подробнее о веб-поиске и поиске по документации в Windsurf](https://docs.windsurf.com/windsurf/cascade/web-search)

### Другие AI-инструменты

Любой AI-инструмент с поддержкой LLMs.txt может использовать эти маршруты, чтобы лучше понимать JS SDK Битрикс24.

#### Примеры для ChatGPT, Claude и других LLM:

- «Используй документацию JS SDK Битрикс24 по адресу https://b24-js-sdk.bx-shef.by/llms.txt»
- «Следуй полному руководству по JS SDK Битрикс24 по адресу https://b24-js-sdk.bx-shef.by/llms-full.txt»
