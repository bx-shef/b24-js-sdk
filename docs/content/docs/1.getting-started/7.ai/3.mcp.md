## Что это

Сайт документации работает как MCP-сервер ([Model Context Protocol](https://modelcontextprotocol.io)). AI-агент, подключённый к нему, сам ищет нужную страницу документации или пример кода и читает их целиком. Копировать страницы в чат не нужно.

Адрес сервера:

```text
https://b24-js-sdk.bx-shef.by/mcp/
```

Транспорт — Streamable HTTP. Авторизация не нужна: сервер отдаёт только открытую документацию и ничего не знает о вашем портале Битрикс24.

::note
Адрес вставляют в настройки AI-агента. Если открыть его в браузере, откроется эта страница; запрос без заголовка `Accept: text/html` (например, `curl`) получит ответ `405`.
::

## Подключение

### Claude Code

```bash
claude mcp add --transport http b24-jssdk https://b24-js-sdk.bx-shef.by/mcp/
```

Проверка: команда `/mcp` в Claude Code показывает сервер `b24-jssdk` и его инструменты.

### Cursor

Файл `.cursor/mcp.json` в проекте (или `~/.cursor/mcp.json` для всех проектов):

```json
{
  "mcpServers": {
    "b24-jssdk": {
      "url": "https://b24-js-sdk.bx-shef.by/mcp/"
    }
  }
}
```

### VS Code (GitHub Copilot)

Файл `.vscode/mcp.json` в проекте:

```json
{
  "servers": {
    "b24-jssdk": {
      "type": "http",
      "url": "https://b24-js-sdk.bx-shef.by/mcp/"
    }
  }
}
```

### Windsurf

Файл `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "b24-jssdk": {
      "serverUrl": "https://b24-js-sdk.bx-shef.by/mcp/"
    }
  }
}
```

### Другие клиенты

Любой клиент MCP с транспортом Streamable HTTP: укажите адрес `https://b24-js-sdk.bx-shef.by/mcp/`.

## Что умеет сервер

### Инструменты

| Инструмент | Что делает |
|---|---|
| `b24-jssdk-list-documentation-pages` | Список всех страниц документации: путь, заголовок и описание |
| `b24-jssdk-list-getting-started-guides` | Руководства раздела «Быстрый старт»: установка, миграция, AI-инструменты |
| `b24-jssdk-get-documentation-page` | Текст страницы по пути в Markdown; блоки REST API v2 и v3 помечены |
| `b24-jssdk-get-example` | Код и описание примера по названию |

### Промпты

| Промпт | Что делает |
|---|---|
| `b24-jssdk-find-api-method` | Подобрать метод SDK или REST API под задачу («создать сделку», «загрузить файл на Диск») |
| `b24-jssdk-generate-example` | Сгенерировать пример кода с SDK под задачу; можно выбрать REST API v2 или v3 |

## Пример

После подключения достаточно попросить агента:

> Как в JS SDK Битрикс24 выгрузить все сделки больше 50 штук? Найди в документации и покажи код.

Агент вызовет `b24-jssdk-list-documentation-pages`, найдёт страницу про `fetchList`, прочитает её через `b24-jssdk-get-documentation-page` и ответит с кодом по документации, а не по памяти.
