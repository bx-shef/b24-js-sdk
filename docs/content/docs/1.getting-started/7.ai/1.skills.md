## Обзор

ИИ-агенты для программирования (Claude Code, Cursor, GitHub Copilot) могут загружать файлы навыков под конкретные задачи из каталога `skills/` вместо чтения всего репозитория. Каждый навык отвечает за одну тему — берите только то, что нужно для текущей задачи.

## Доступные навыки

| Навык | Когда использовать |
|---|---|
| `b24jssdk-core` | Загружается первым: выбор точки входа (B24Hook / B24Frame / B24OAuth), запуск и завершение, классификация ошибок, настройка hardErrorCodes / softErrorCodes / retryOnNetworkError |
| `b24jssdk-rest` | actions.v{2,3}.*.make() — call / batch / callList / fetchList / callTail / fetchTail / batchByChunk; структура AjaxResult; маршрутизация v2/v3 (без белого списка для v3) |
| `b24jssdk-filtering` | Фильтр v2 с префиксами в ключах и v3 с массивом троек; операторы; даты через Text.toB24Format; правило удаления order в callList |
| `b24jssdk-frame-ui` | Менеджеры, доступные только в iframe: slider / dialog (selectUser/Users/CRM/Access) / parent / placement (с setValue) / options / auth |
| `b24jssdk-helpers` | useB24Helper, B24HelperManager, клиент Pull, форматирование валют, настройки приложения и пользователя |
| `b24jssdk-recipes` | 12 готовых мини-приложений на TypeScript, типы проверяются в CI командой pnpm run skills:typecheck |
| `b24jssdk-vibecode` | Когда сочетать SDK с HTTP API VibeCode |

## Использование

Каждый навык — обычный Markdown-файл `skills/<name>/SKILL.md`, оформленный по открытому стандарту [Agent Skills](https://agentskills.io), поэтому его может использовать любой агент, умеющий читать файлы. Есть два способа получить навыки: **загрузить один навык прямо в сессию** для быстрой работы или **установить** их в свой проект, чтобы они всегда были под рукой.

### Загрузка из этого репозитория

Если рабочий каталог — клон этого репозитория, сошлитесь на навык по пути:

```
@skills/b24jssdk-core/SKILL.md
```

Указывайте сам файл `SKILL.md`, а не каталог `skills/b24jssdk-core`: ссылка на каталог лишь перечисляет его файлы и не подтягивает содержимое навыка. Путь разрешается относительно текущего каталога, поэтому так работает только когда рабочий каталог — сам `b24jssdk`. Чтобы использовать навыки в своём приложении, установите их одним из способов ниже.

### Claude Code — установка в проект

Скопируйте каталоги навыков в `.claude/skills/` своего проекта. Структура уже совпадает с ожидаемой Claude Code (`.claude/skills/<name>/SKILL.md`), преобразование не нужно:

```bash
mkdir -p .claude/skills
cp -R path/to/b24jssdk/skills/b24jssdk-* .claude/skills/
```

Добавьте `.claude/skills/` в систему контроля версий, чтобы навыки были у всех участников проекта. Claude загружает навык, когда он уместен, или вы можете вызвать его напрямую командой `/b24jssdk-core`.

### Claude Code — личная установка

Чтобы одни и те же навыки были доступны во **всех** ваших проектах, скопируйте их в личный каталог навыков:

```bash
mkdir -p ~/.claude/skills
cp -R path/to/b24jssdk/skills/b24jssdk-* ~/.claude/skills/
```

Личные навыки (`~/.claude/skills/<name>/SKILL.md`) доступны в каждом проекте, ничего не нужно коммитить.

### Claude Code — плагин и маркетплейс

Пока недоступно. В этом репозитории **нет `.claude-plugin/marketplace.json`**, поэтому `/plugin marketplace add bitrix24/b24jssdk` не работает. Используйте установку в проект или личную установку, описанные выше.

### Cursor / Windsurf / GitHub Copilot — сначала скопируйте файлы

В этих инструментах нет личного каталога навыков, поэтому сначала скопируйте файлы навыков в свой проект, а затем укажите их инструменту:

```bash
# clone the whole repo…
git clone https://github.com/bx-shef/b24-js-sdk

# …or pull only the skills with a sparse checkout
git clone --depth 1 --filter=blob:none --sparse https://github.com/bx-shef/b24-js-sdk
cd b24-js-sdk && git sparse-checkout set skills

# …or add it as a submodule inside your project
git submodule add https://github.com/bx-shef/b24-js-sdk vendor/b24jssdk
```

Затем сошлитесь на `skills/<name>/SKILL.md`: в **Cursor / Windsurf** перетащите файл в чат или используйте ссылки `@`-file (или `@docs`); в **GitHub Copilot** прикрепите его как документ рабочей области или вставьте путь в чат.

### Загрузка по опубликованному URL (без клонирования)

Каталог `skills/` также отдаётся сайтом документации по адресу `/.well-known/skills/`, поэтому навык можно скачать без клонирования репозитория:

```bash
curl -O https://b24-js-sdk.bx-shef.by/.well-known/skills/b24jssdk-core/SKILL.md
```

Каждый навык лежит по адресу `/.well-known/skills/b24jssdk-<name>/SKILL.md`. Ответы кэшируются на 24 часа. Это удобно для быстрого копирования (положите файл в `.claude/skills/<name>/` или прикрепите в другом инструменте) и для средств, которые находят навыки по HTTP.

## Порядок загрузки

Всегда начинайте с `b24jssdk-core`: он описывает выбор точки входа и жизненный цикл SDK, на которые опираются все остальные навыки. Затем добавляйте тематические навыки под задачу:

1. `b24jssdk-core` (всегда первым)
2. `b24jssdk-rest` — если выполняете REST-запросы
3. `b24jssdk-filtering` — если строите фильтры или запросы списков
4. `b24jssdk-frame-ui` — если работаете внутри iframe-приложения
5. `b24jssdk-helpers` — если используете вспомогательные утилиты или Pull
6. `b24jssdk-recipes` — для готовых примеров от начала до конца

Не загружайте все навыки сразу: описания рассчитаны на выборочное использование, чтобы контекст оставался сфокусированным.
