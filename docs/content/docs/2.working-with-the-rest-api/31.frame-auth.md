## Геттеры
### isAdmin
```ts-type
get isAdmin(): boolean
```

Возвращает `true`, если у текущего пользователя есть права администратора, иначе `false`.

### getAuthData
```ts-type
getAuthData(): false | AuthData
```

Возвращает данные авторизации [`AuthData`{lang="ts-type"}](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/types/auth.ts), если они не истекли. Если истекли, возвращает `false`.

### refreshAuth
```ts-type
refreshAuth(): Promise<AuthData>
```

Обновляет данные авторизации через родительское окно и возвращает обновлённые данные [`AuthData`{lang="ts-type"}](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/types/auth.ts).

Вместо некорректного состояния метод отклоняется: `JSSDK_FRAME_REFRESH_AUTH_TIMEOUT`, если родительское окно не ответило за 10 секунд, и `JSSDK_FRAME_REFRESH_AUTH_BAD_RESPONSE`, если ответило без пригодного `AUTH_EXPIRES`. В обоих случаях прежний токен остаётся нетронутым, поэтому повтор имеет смысл. См. [Коды ошибок](/docs/working-with-the-rest-api/error-codes/).

::note
Одновременные вызовы **объединяются**: пока обновление выполняется, каждый следующий вызов получает тот же промис, а не отправляет родительскому окну второе сообщение `refreshAuth`. Это важно, потому что `B24Frame` держит два транспорта (`restApi:v2` и `restApi:v3`) на одном `AuthManager`, а слишком частое обновление, по предупреждению Битрикс, может привести к автоматической блокировке приложения. Обновление, начатое *после* завершения предыдущего, — настоящее обновление: окно объединения — это только время, пока одно из них реально выполняется.
::

::tip
Вызывать этот метод самостоятельно приходится редко. SDK обновляет **уже истёкший** токен перед запросом — действующий используется как есть, поэтому вызов не стоит обновления — и обновляет снова, если портал ответил `401`. Если ваше приложение читает токен через `getAuthData()` и использует его вне SDK, лучше применять [`keepAuthFresh`](/docs/working-with-the-rest-api/frame-initialize-b24-frame/#сохранение-токена-актуальным), чем собственный таймер.
::

### getUniq
```ts-type
getUniq(prefix: string): string
```

Возвращает уникальную строку из заданного префикса и `AuthData.memberId`{lang="ts-type"}.

> Используется в `B24PullClientManager`{lang="ts-type"}
