Каждый тип из [`packages/jssdk/src/types/`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/index.ts) реэкспортируется из `@bitrix24/b24jssdk`. Отдельная страница сегодня есть только у части из них; остальные либо описаны как часть класса или менеджера, который их использует, либо ещё предстоит описать. Эта таблица — карта.

## Отдельные страницы

| Модуль | Что охватывает | Страница |
| --- | --- | --- |
| `types/common.ts` | псевдонимы скаляров, `Fields`, `MultiField`, `UserFieldType`, `DataType` | [Общие типы](/docs/working-with-the-rest-api/types-common/) |
| `types/payloads.ts` | `PayloadTime`, `GetPayload`, `ListPayload`, `BatchPayload`, `SuccessPayload`, `Payload` | [Типы полезной нагрузки](/docs/working-with-the-rest-api/types-payloads/) |
| `types/b24.ts` | `TypeB24`, `ApiVersion` | [TypeB24](/docs/working-with-the-rest-api/types-type-b24/) |
| `core/result.ts` | `IResult` (реализуется `Result` / `AjaxResult`) | [IResult](/docs/working-with-the-rest-api/types-iresult/) |

## Описаны на других страницах

У этих модулей нет собственной страницы типов — их типы описаны на странице класса или возможности, которые их используют.

| Модуль | Где описан |
| --- | --- |
| `types/http.ts` | [Core HTTP](/docs/working-with-the-rest-api/core-http/) |
| `types/limiters.ts` | [Лимитеры](/docs/working-with-the-rest-api/limiters/) |
| `types/logger.ts` | [Журналирование](/docs/working-with-the-rest-api/logging/) |
| `types/b24-helper.ts` | [Helper](/docs/working-with-the-rest-api/helper-use-b24-helper/) |
| `types/pull.ts` | [Pull](/docs/working-with-the-rest-api/pull/) |

| `core/actions/v3/deferred-batch.ts` (`DeferredBatchJob`, `DeferredBatchStatus`, …) | [DeferredBatch](/docs/working-with-the-rest-api/deferred-batch-rest-api-ver3/) |

## В планах (страницы по областям)

У модулей типов по областям пока нет отдельной страницы. Они отслежены как дальнейшая работа в issue #125 и **выходят за рамки v1.2.0** (где приоритет у `common` и `payloads`).

| Модуль | Состояние |
| --- | --- |
| `types/auth.ts` | В планах (частично описан на странице [Frame auth](/docs/working-with-the-rest-api/frame-auth/)) |
| `types/placement/index.ts`, `types/placement/uf.ts` | В планах ([Frame placement](/docs/working-with-the-rest-api/frame-placement/) документирует API `PlacementManager`, но форма поля `IPlacementUF` пока не описана) |
| `types/user.ts` | В планах |
| `types/handler.ts` | В планах |
| `types/crm/index.ts`, `types/crm/entity-type.ts`, `types/crm/item-delivery.ts`, `types/crm/item-payment.ts`, `types/crm/productrow.ts` | В планах |
| `types/catalog/index.ts` | В планах |
| `types/bizproc/index.ts`, `types/bizproc/activity/index.ts` | В планах |
| `types/event/index.ts` | В планах |
