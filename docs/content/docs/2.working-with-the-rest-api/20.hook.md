::caution{title="⚠️ ВНИМАНИЕ: БЕЗОПАСНОСТЬ"}
Объект `B24Hook`{lang="ts-type"} предназначен **только для использования на сервере**.

- URL вебхука содержит секретный ключ доступа. **Он не должен попадать в клиентский код (браузер, мобильное приложение)**.
- Для клиентской стороны используйте [`B24Frame`](/docs/working-with-the-rest-api/frame/).
- HTTP-клиент по умолчанию создаётся с включённым предупреждением о клиентской стороне — см. [`offClientSideWarning`](#offclientsidewarning).
::

## Обзор

`B24Hook`{lang="ts-type"} — класс SDK для работы с REST API Битрикс24 через входящий вебхук. Вебхук — это URL, в котором уже есть идентификатор пользователя и секретный токен, поэтому запросы авторизуются без обмена по OAuth.

Класс наследует `AbstractB24`{lang="ts-type"} и реализует [`TypeB24`{lang="ts-type"}](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/types/b24.ts). Весь REST-интерфейс (`actions.v2.*`, `actions.v3.*`, `tools.*`) доступен сразу после создания экземпляра — шага `await b24.init()` нет.

## Создание экземпляра B24Hook

Экземпляр `B24Hook`{lang="ts-type"} можно создать двумя способами.

### Из полного URL вебхука

Рекомендуемый способ, если URL вебхука хранится в одной переменной окружения.

```ts
import { B24Hook } from '@bitrix24/b24jssdk'

const $b24 = B24Hook.fromWebhookUrl('https://your_domain.bitrix24.com/rest/1/k32t88gf3azpmwv3/')
```

#### Сигнатура метода

```ts-type
static fromWebhookUrl(
  url: string,
  options?: {
    restrictionParams?: Partial<RestrictionParams>
    httpOptions?: TypeHttpOptions
  }
): B24Hook
```

#### Параметры

| Параметр | Тип | Обязательный | Описание |
|----|----|----|----|
| `url` | `string`{lang="ts-type"} | Да | Полный URL вебхука. Поддерживаются оба формата: `/rest/<userId>/<secret>` (REST v2) и `/rest/api/<userId>/<secret>` (REST v3). |
| `options.restrictionParams` | `Partial<RestrictionParams>`{lang="ts-type"} | Нет | Переопределение настроек по умолчанию: лимит частоты, лимит времени выполнения, адаптивная задержка. См. [Ограничители](/docs/working-with-the-rest-api/limiters/). |
| `options.httpOptions` | `TypeHttpOptions`{lang="ts-type"} | Нет | Настройки axios для обоих транспортов, применяются поверх значений SDK по умолчанию — прежде всего `adapter`. Ключи вне `TypeHttpOptions`{lang="ts-type"} отбрасываются при создании, их имена попадают в лог. См. [Настройка экземпляра axios](/docs/working-with-the-rest-api/core-http/#configuring-the-axios-instance). |

Статическая фабрика проверяет URL: нужен HTTPS, путь должен соответствовать одному из поддерживаемых видов, а идентификатор пользователя должен быть числом. В остальных случаях сразу выбрасывается исключение.

### Из параметров

Используйте этот конструктор, если части вебхука хранятся раздельно (например, URL портала в одной переменной окружения, а токен — в менеджере секретов).

```ts
import { B24Hook } from '@bitrix24/b24jssdk'

const $b24 = new B24Hook({
  b24Url: 'https://your_domain.bitrix24.com',
  userId: 1,
  secret: 'k32t88gf3azpmwv3'
})
```

#### Сигнатура конструктора

```ts-type
constructor(
  b24HookParams: B24HookParams,
  options?: {
    restrictionParams?: Partial<RestrictionParams>
    httpOptions?: TypeHttpOptions
  }
)
```

`options.restrictionParams` настраивает лимит частоты, лимит времени выполнения и адаптивную задержку — см. [Ограничители](/docs/working-with-the-rest-api/limiters/). `options.httpOptions` содержит настройки axios для обоих транспортов поверх значений SDK по умолчанию — прежде всего `adapter`; см. [Настройка экземпляра axios](/docs/working-with-the-rest-api/core-http/#configuring-the-axios-instance). Ключи вне `TypeHttpOptions`{lang="ts-type"} отбрасываются при создании, их имена попадают в лог.

#### Поля `B24HookParams`

| Поле | Тип | Описание |
|----|----|----|
| `b24Url` | `string`{lang="ts-type"} | URL портала Битрикс24 (`https://your_domain.bitrix24.com`). |
| `userId` | `number`{lang="ts-type"} | Идентификатор пользователя, которому принадлежит вебхук. |
| `secret` | `string`{lang="ts-type"} | Секретный токен вебхука. |

## Быстрый пример

```ts
import { B24Hook, EnumCrmEntityTypeId, LoggerFactory } from '@bitrix24/b24jssdk'

const $logger = LoggerFactory.createForBrowser('node:hook', process.env.NODE_ENV === 'development')

if (!process.env.B24_HOOK) {
  throw new Error('B24_HOOK env variable is required')
}

const $b24 = B24Hook.fromWebhookUrl(process.env.B24_HOOK)

const response = await $b24.actions.v2.call.make<{ id: number, title: string }>({
  method: 'crm.item.list',
  params: {
    entityTypeId: EnumCrmEntityTypeId.company,
    select: ['id', 'title']
  },
  requestId: 'companies-list'
})

if (!response.isSuccess) {
  $logger.error('REST error', { messages: response.getErrorMessages() })
  process.exit(1)
}

$logger.info('Companies', response.getData()?.result)
```

## Геттеры

### `auth`

```ts-type
get auth(): AuthActions
```

Возвращает экземпляр [`AuthHookManager`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/hook/auth.ts), который реализует [`AuthActions`{lang="ts-type"}](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/types/auth.ts):

- `getAuthData()` — возвращает синтетический `AuthData`{lang="ts-type"}, собранный из секрета вебхука. `expires` всегда `0` (токены вебхуков не истекают).
- `refreshAuth()` — для совместимости с `B24OAuth`{lang="ts-type"}; возвращает те же данные без сетевого запроса.
- `getUniq(prefix: string)` — возвращает `<prefix>_<member_id>`{lang="ts-type"}, используется клиентом Pull и другими помощниками.
- `isAdmin` — всегда `true`{lang="ts-type"} (предполагается, что вебхуки создают администраторы).

### `isInit`

```ts-type
get isInit(): boolean
```

Сразу после создания всегда `true`{lang="ts-type"} — для `B24Hook`{lang="ts-type"} вызывать `init()` не нужно.

### `actions` / `tools`

Те же, что у любого класса `TypeB24`{lang="ts-type"}. См.:

- [`CallV2.make`](/docs/working-with-the-rest-api/call-rest-api-ver2/) / [`CallV3.make`](/docs/working-with-the-rest-api/call-rest-api-ver3/)
- [`CallListV2.make`](/docs/working-with-the-rest-api/call-list-rest-api-ver2/) / [`CallListV3.make`](/docs/working-with-the-rest-api/call-list-rest-api-ver3/)
- [`FetchListV2.make`](/docs/working-with-the-rest-api/fetch-list-rest-api-ver2/) / [`FetchListV3.make`](/docs/working-with-the-rest-api/fetch-list-rest-api-ver3/)
- [`BatchV2.make`](/docs/working-with-the-rest-api/batch-rest-api-ver2/) / [`BatchV3.make`](/docs/working-with-the-rest-api/batch-rest-api-ver3/)
- [`BatchByChunkV2.make`](/docs/working-with-the-rest-api/batch-by-chunk-rest-api-ver2/) / [`BatchByChunkV3.make`](/docs/working-with-the-rest-api/batch-by-chunk-rest-api-ver3/)
- [`tools.healthCheck.make`](/docs/working-with-the-rest-api/tools-health-check/), [`tools.ping.make`](/docs/working-with-the-rest-api/tools-ping/)

## Методы

### `getTargetOrigin`

```ts-type
getTargetOrigin(): string
```

Возвращает origin портала (`https://your_domain.bitrix24.com`).

### `getTargetOriginWithPath`

```ts-type
getTargetOriginWithPath(): Map<ApiVersion, string>
```

Возвращает REST-адрес для каждой версии API:

- `ApiVersion.v2`{lang="ts-type"} → `https://your_domain.bitrix24.com/rest/<userId>/<secret>`
- `ApiVersion.v3`{lang="ts-type"} → `https://your_domain.bitrix24.com/rest/api/<userId>/<secret>`

### `offClientSideWarning`

```ts-type
offClientSideWarning(): void
```

Отключает предупреждение, которое оба HTTP-клиента выводят, когда `B24Hook`{lang="ts-type"} обнаружен в браузерной среде — в основном потоке или в воркере (Web, Shared, Service Worker), где сборка так же доступна для чтения. Используйте, только если вы намеренно проксируете вебхук через серверную обёртку, которая убирает секрет до любого запроса из браузера.

### `getHttpClient` / `setHttpClient`

```ts-type
getHttpClient(version: ApiVersion): TypeHttp
setHttpClient(version: ApiVersion, client: TypeHttp): void
```

Прямой доступ к HTTP-транспортам (по одному на версию REST API). См. [справочник Http](/docs/working-with-the-rest-api/core-http/).

### `setRestrictionManagerParams`

```ts-type
setRestrictionManagerParams(params: RestrictionParams): Promise<void>
```

Заменяет настройки лимита частоты, лимита времени выполнения и адаптивной задержки сразу у клиентов v2 и v3. См. [Ограничители](/docs/working-with-the-rest-api/limiters/).

### `getLogger` / `setLogger`

```ts-type
getLogger(): LoggerInterface
setLogger(logger: LoggerInterface): void
```

Возвращает или заменяет логгер, который использует SDK и который передаётся в HTTP-клиенты. См. [Логгер](/docs/working-with-the-rest-api/logger/).

### `destroy`

```ts-type
destroy(): void
```

Освобождает внутренние ссылки. Вызывайте перед завершением процесса или при отказе от долгоживущего экземпляра.

```ts
function shutdown() {
  $b24.destroy()
}
```

## Частые вопросы

::accordion

:::accordion-item{label="Где взять URL вебхука?"}
Битрикс24 → Разработчикам → Другое → Входящий вебхук. См. [официальную документацию](https://apidocs.bitrix24.com/local-integrations/local-webhooks.html#vhodyashij-vebhuk).
:::

:::accordion-item{label="Может ли один экземпляр B24Hook обслуживать весь сервер?"}
Да. Создайте экземпляр один раз при запуске и используйте его во всех запросах — HTTP-клиенты переиспользуют экземпляр axios и состояние ограничителей.
:::

:::accordion-item{label="Почему fromWebhookUrl выбрасывает «Webhook requires HTTPS protocol»?"}
Фабрика намеренно отклоняет URL с `http://`. Секреты вебхуков должны передаваться только по TLS.
:::

:::accordion-item{label="Что означает «Access denied»?"}
У пользователя вебхука нет прав на вызываемый REST-метод, либо сам вебхук отозван. Создайте вебхук заново с нужными правами доступа.
:::
