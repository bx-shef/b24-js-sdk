Это индекс всех **значений**, которые `@bitrix24/b24jssdk` экспортирует публично: классов, enum, констант и функций, доступных для импорта и использования во время выполнения. Они сгруппированы по областям. Для каждого экспорта указано, что это, и даны ссылки на руководство и исходный код. Экспорты, которые являются только `type` и `interface`, здесь не перечислены — для них есть отдельная страница, [Обзор типов](/docs/working-with-the-rest-api/types-index/).

Страница намеренно **не** повторяет сигнатуры и таблицы параметров: они живут в руководствах, где сверяются с исходным кодом, а их примеры компилируются в CI. Эта страница — карта, а не сама территория. Постраничные справочники по отдельным символам — отдельный, более поздний слой; он отслеживается в [#315](https://github.com/bitrix24/b24jssdk/issues/315).

::note
Вы здесь впервые? Начните с [Быстрого старта](/docs/getting-started/) и выберите точку входа ниже — этот выбор определяет всё остальное.
::

## Действия — вызов REST API

Поверхность `$b24.actions.v{2,3}.*`. `v2` и `v3` — разные диалекты, а не версии одного и того же.

| Экспорт | Что это | Руководство |
| --- | --- | --- |
| [`versionManager`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/core/version-manager.ts) | Направляет метод в транспорт v2 или v3. | — |
| [`ApiVersion`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/types/b24.ts) | Дискриминатор `restApi:v2` / `restApi:v3`. | [руководство](/docs/working-with-the-rest-api/limiters/) |
| [`HttpV2`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/core/http/v2.ts) | Транспорт v2. | [руководство](/docs/working-with-the-rest-api/core-http/) |
| [`HttpV3`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/core/http/v3.ts) | Транспорт v3. | [руководство](/docs/working-with-the-rest-api/core-http/) |
| [`FilterV3`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/tools/filter-v3.ts) | Типизированный построитель фильтра v3 — грамматики «массив троек». | [руководство](/docs/working-with-the-rest-api/filtering/) |
| [`BatchRefV3`](https://github.com/bitrix24/b24jssdk/blob/main/packages/jssdk/src/tools/batch-ref-v3.ts) | Маркеры `$ref` / `$refArray` для подстановки результатов одних команд в другие в пакетном запросе (batch) v3. | [руководство](/docs/working-with-the-rest-api/batch-rest-api-ver3/) |

Отложенные пакеты (deferred batch) доступны через `$b24.actions.v3.deferredBatch`, а не через отдельный экспорт. Их типы (`DeferredBatchJob` и остальные) перечислены в [индексе типов](/docs/working-with-the-rest-api/types-index/) и описаны в [руководстве по DeferredBatch](/docs/working-with-the-rest-api/deferred-batch-rest-api-ver3/).
