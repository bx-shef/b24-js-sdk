## Обзор

`useB24Helper()`{lang="ts-type"} — фабрика: каждый вызов возвращает новое замыкание со своим слотом [`B24HelperManager`](/docs/entry-points/helper/) и своим состоянием клиента Pull. Она объединяет инициализацию при повторных отрисовках и централизует уничтожение при размонтировании.

```ts
import { useB24Helper, LoadDataType } from '@bitrix24/b24jssdk'

const {
  initB24Helper,
  isInitB24Helper,
  destroyB24Helper,
  getB24Helper,
  usePullClient,
  useSubscribePullClient,
  startPullClient
} = useB24Helper()
```

## Возвращаемый API

### `initB24Helper`

```ts-type
initB24Helper(
  $b24: TypeB24,
  dataTypes?: LoadDataType[],
  requestId?: string
): Promise<B24HelperManager>
```

Создаёт `B24HelperManager`{lang="ts-type"} (один раз на замыкание) и вызывает `loadData(dataTypes, requestId)`. Последующие вызовы ничего не делают — они возвращают тот же менеджер без повторной загрузки. `dataTypes` по умолчанию равен `[LoadDataType.App, LoadDataType.Profile]`{lang="ts-type"}; `requestId` по умолчанию — `'helper-load-data'`{lang="ts-type"}.

### `isInitB24Helper`

```ts-type
isInitB24Helper(): boolean
```

Возвращает `true`{lang="ts-type"}, если `initB24Helper` хотя бы раз завершился.

### `destroyB24Helper`

```ts-type
destroyB24Helper(): void
```

Вызывает `destroy()` у менеджера (закрывая клиент Pull) и сбрасывает флаги замыкания, поэтому новый вызов `initB24Helper` загрузит данные заново.

### `getB24Helper`

```ts-type
getB24Helper(): B24HelperManager
```

Возвращает действующий менеджер. Если вызвать до `initB24Helper`, выбросит `'B24HelperManager is not initialized. You need to call initB24Helper first.'`{lang="ts-type"}.

### Помощники клиента Pull

```ts-type
usePullClient(): void
useSubscribePullClient(callback: (message: TypePullMessage) => void, moduleId?: string): void
startPullClient(): void
```

Тонкие обёртки над одноимёнными методами `B24HelperManager`{lang="ts-type"}. Порядок: `usePullClient` → `useSubscribePullClient` (один или несколько раз) → `startPullClient`. Вызов `useSubscribePullClient` или `startPullClient` до `usePullClient` выбросит `'PullClient is not initialized. You need to call usePullClient first.'`{lang="ts-type"}. См. [Клиент Pull](/docs/entry-points/pull/).

## Перечисление `LoadDataType`

```ts-type
enum LoadDataType {
  App = 'app',
  Profile = 'profile',
  Currency = 'currency',
  AppOptions = 'appOptions',
  UserOptions = 'userOptions'
}
```

Каждое значение запускает в пакетном запросе один REST-метод (два — для `Currency`); см. таблицу на странице [B24HelperManager](/docs/entry-points/helper/#перечисление-loaddatatype).

## Пример для Vue

```vue
<script setup lang="ts">
import { onMounted, onUnmounted } from 'vue'
import {
  initializeB24Frame,
  useB24Helper,
  LoadDataType,
  type B24Frame
} from '@bitrix24/b24jssdk'

const { initB24Helper, getB24Helper, destroyB24Helper } = useB24Helper()

let $b24: undefined | B24Frame

onMounted(async () => {
  $b24 = await initializeB24Frame()
  await initB24Helper($b24, [
    LoadDataType.Profile,
    LoadDataType.App,
    LoadDataType.Currency
  ])
  console.log('User:', getB24Helper().profileInfo.data)
})

onUnmounted(() => {
  destroyB24Helper()
  $b24?.destroy()
})
</script>
```
