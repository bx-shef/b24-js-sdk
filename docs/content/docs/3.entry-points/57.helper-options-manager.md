`OptionsManager`{lang="ts-type"} создаётся дважды — для `app.option.get` и для `user.option.get`. Доступен через [`B24HelperManager.appOptions`](/docs/entry-points/helper/#profileinfo--appinfo--paymentinfo--licenseinfo--currency--appoptions--useroptions) и [`B24HelperManager.userOptions`](/docs/entry-points/helper/#profileinfo--appinfo--paymentinfo--licenseinfo--currency--appoptions--useroptions). На сервере значения опций рассматриваются как исходные строки, а преобразование выполняется при чтении.

## Использование

```ts
import { useB24Helper, LoadDataType } from '@bxshefby/b24jssdk'

const { initB24Helper, getB24Helper } = useB24Helper()
await initB24Helper($b24, [LoadDataType.AppOptions, LoadDataType.UserOptions])

const helper = getB24Helper()

// Read with a default
const filters = helper.userOptions.getJsonObject('listFilters', {})
const itemsPerPage = helper.userOptions.getInteger('itemsPerPage', 20)

// Persist
await helper.appOptions.save(
  { theme: 'dark' },
  { moduleId: 'main', command: 'optionsChanged', params: { theme: 'dark' } }
)
```

## Типизированные геттеры

| Метод | Возвращает | По умолчанию | Примечания |
|----|----|----|----|
| `getJsonArray(key, def?)` | `any[]`{lang="ts-type"} | `[]`{lang="ts-type"} | Разбирает JSON, принимает и JSON-объекты (возвращает `Object.values`). |
| `getJsonObject(key, def?)` | `object`{lang="ts-type"} | `{}`{lang="ts-type"} | Разбирает JSON, при сбое возвращает `def`. |
| `getFloat(key, def?)` | `number`{lang="ts-type"} | `0.0`{lang="ts-type"} | Использует `Text.toNumber`. |
| `getInteger(key, def?)` | `number`{lang="ts-type"} | `0`{lang="ts-type"} | Использует `Text.toInteger`. |
| `getBoolYN(key, def?)` | `boolean`{lang="ts-type"} | `true`{lang="ts-type"} | `'Y'` → `true`, `'N'` → `false`. |
| `getBoolNY(key, def?)` | `boolean`{lang="ts-type"} | `false`{lang="ts-type"} | То же преобразование, что у `getBoolYN`, но другое значение по умолчанию. |
| `getString(key, def?)` | `string`{lang="ts-type"} | `''`{lang="ts-type"} | Вызывает `.toString()`. |
| `getDate(key, def?)` | `null \| DateTime`{lang="ts-type"} | `null`{lang="ts-type"} | Использует `Text.toDateTime` (Luxon). |

## Статические помощники


`TypeOption`{lang="ts-type"} перечисляет поддерживаемые виды значений (`NotSet / JsonArray / JsonObject / FloatVal / IntegerVal / BoolYN / StringVal`).

## Методы кеша

```ts-type
get data(): Map<string, any>
reset(): void
```

`data` — исходное соответствие «ключ → строка». `reset()` очищает кеш в памяти, не обращаясь к серверу.

## Сохранение

```ts-type
save(
  options: Record<string, any>,
  optionsPull?: { moduleId: string, command: string, params: any },
  requestId?: string
): Promise<Result>
```

Выполняет один пакетный вызов:

1. `app.option.set` для `appOptions` / `user.option.set` для `userOptions` с переданными `options`.
2. Необязательно `pull.application.event.add`, чтобы остальные клиенты узнали об изменении.

Оба вызова используют `isHaltOnError: true`. Возвращает обёртку [`Result`{lang="ts-type"}](/docs/tools/core-result/).

::note
`save()` **не** обновляет локальный кеш. Вызовите `getB24Helper().loadData([LoadDataType.AppOptions])` (или повторите `initB24Helper`), если нужно, чтобы новое состояние было видно последующим чтениям `getX()`.
::
