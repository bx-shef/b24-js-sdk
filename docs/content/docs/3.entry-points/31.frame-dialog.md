`DialogManager` доступен через [`$b24.dialog`](/docs/entry-points/frame/#dialog) у экземпляра `B24Frame` и работает только когда приложение отображается внутри iframe Битрикс24 (для связи с родительским окном используется `postMessage`).

Он повторяет прежние помощники [`BX24.selectUser`](https://apidocs.bitrix24.com/sdk/bx24-js-sdk/system-dialogues/bx24-select-user.html), [`BX24.selectUsers`](https://apidocs.bitrix24.com/sdk/bx24-js-sdk/system-dialogues/bx24-select-users.html), [`BX24.selectAccess`](https://apidocs.bitrix24.com/sdk/bx24-js-sdk/system-dialogues/bx24-select-access.html) и [`BX24.selectCRM`](https://apidocs.bitrix24.com/sdk/bx24-js-sdk/system-dialogues/bx24-select-crm.html), но вместо обратных вызовов возвращает строго типизированные `Promise`.

## Методы

### selectUser

```ts-type
async selectUser(): Promise<null|SelectedUser>
```

Показывает стандартный диалог выбора одного сотрудника компании.

Промис разрешается объектом [`SelectedUser`](#selecteduser) или `null`, если пользователь закрыл диалог, ничего не выбрав.

```ts
// ... /////
$b24 = await initializeB24Frame()
// ... /////
const makeSelectUser = async() => {
  const selectedUser = await $b24.dialog.selectUser()
  if (!selectedUser) {
    return
  }
  $logger.info(selectedUser)
}
```

### selectUsers

```ts-type
async selectUsers(): Promise<SelectedUser[]>
```

Показывает стандартный диалог выбора нескольких сотрудников компании.

Промис разрешается массивом объектов [`SelectedUser`](#selecteduser). Массив пуст, если пользователь подтвердил диалог, никого не выбрав.

```ts
import { SelectedUser } from '@bxshefby/b24jssdk'

// ... /////
$b24 = await initializeB24Frame()
// ... /////
const makeSelectUsers = async() => {
  const selectedUsers = await $b24.dialog.selectUsers()

  const list = selectedUsers.map((row: SelectedUser): string => {
    return [`[id: ${row.id}]`, row.name].join(' ')
  })

  $logger.info(selectedUsers, list)
}
```

### selectAccess

```ts-type
async selectAccess(blockedAccessPermissions?: string[]): Promise<SelectedAccess[]>
```

Показывает стандартный диалог выбора прав доступа (подразделения, группы, отдельные пользователи и предопределённые коды прав, например `AU` или `CR`).

| Параметр                    | Тип        | Описание                                                                                                                                   |
|-----------------------------|------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| `blockedAccessPermissions`  | `string[]` | Необязательный список кодов прав, которые нужно отключить в диалоге. По умолчанию `[]`. Полезно, если часть прав уже выдана в другом месте. |

Промис разрешается массивом записей [`SelectedAccess`](#selectedaccess).

```ts
// ... /////
$b24 = await initializeB24Frame()
// ... /////
const makeSelectAccess = async() => {
  const selected = await $b24.dialog.selectAccess(['AU'])

  $logger.info(
    selected.map(row => `${row.id} → ${row.name}`)
  )
}
```

### selectCRM

```ts-type
async selectCRM(params?: SelectCRMParams): Promise<SelectedCRM>
```

Показывает стандартный диалог выбора сущностей CRM (лиды, контакты, компании, сделки, предложения).

| Параметр                   | Тип                             | Описание                                                                                                                                                                      |
|----------------------------|---------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `params.entityType`        | `SelectCRMParamsEntityType[]`   | Какие типы сущностей показывать вкладками в диалоге. Допустимые значения: `lead`, `contact`, `company`, `deal`, `quote`.                                                      |
| `params.multiple`          | `boolean`                       | Разрешить множественный выбор. По умолчанию `false`.                                                                                                                          |
| `params.value`             | `SelectCRMParamsValue`          | Необязательное сопоставление ID сущностей, которые нужно отметить изначально. Применяется **только при `multiple`, равном `true`** — в режиме одиночного выбора игнорируется.  |

Промис разрешается объектом [`SelectedCRM`](#selectedcrm), свойства которого (`lead`, `contact`, `company`, `deal`, `quote`) — настоящие массивы JavaScript из [`SelectedCRMEntity`](#selectedcrmentity). Для типов сущностей, которые пользователь не выбрал (или которые вы не запрашивали), значение остаётся `undefined`, а не пустым массивом.

::note
Начиная с v1.1.0 (#21) `selectCRM` всегда возвращает настоящие массивы. Ранние версии передавали данные родительского окна как есть, поэтому каждая группа на деле была `Record<string, SelectedCRMEntity>` (например, `{ 0: {...}, 1: {...} }`) — вызов `.length` или `.map()` для неё возвращал `undefined`. Код, написанный по описанным типам, продолжает работать; единственное отличие в поведении — теперь форма данных во время выполнения совпадает с типами.
::

```ts
// ... /////
$b24 = await initializeB24Frame()
// ... /////
const makeSelectCRM = async() => {
  const selected = await $b24.dialog.selectCRM({
    entityType: ['contact', 'company'],
    multiple: true,
    value: {
      contact: [42],
      company: [7]
    }
  })

  selected.contact?.forEach((row) => {
    $logger.info(`[${row.id}] ${row.title} — ${row.url}`)
  })

  selected.company?.forEach((row) => {
    $logger.info(`[${row.id}] ${row.title}`)
  })
}
```

::note
Режим одиночного выбора (`multiple: false`) по-прежнему возвращает тот же вид `SelectedCRM` — в группах просто не больше одного элемента. Чтобы получить его, используйте `selected.contact?.[0]`.
::

## Типы данных

### SelectedUser

Один сотрудник компании, выбранный через `selectUser` / `selectUsers`. Флаги `sub` и `sup` описывают иерархическую связь с текущим пользователем.

| Поле       | Тип            | Описание                                                                                   |
|------------|----------------|--------------------------------------------------------------------------------------------|
| `id`       | `NumberString` | Идентификатор пользователя — строка с числовым значением (например, `"42"`).               |
| `name`     | `string`       | Отформатированное отображаемое имя.                                                        |
| `photo`    | `string`       | URL аватара пользователя.                                                                  |
| `position` | `string`       | Должность пользователя.                                                                    |
| `url`      | `string`       | URL профиля пользователя на портале.                                                       |
| `sub`      | `boolean`      | `true`, если выбранный пользователь — подчинённый текущего пользователя.                   |
| `sup`      | `boolean`      | `true`, если выбранный пользователь — руководитель текущего пользователя.                  |

### SelectedAccess

Одна запись, возвращаемая `selectAccess`.

| Поле   | Тип      | Описание                                                                                                 |
|--------|----------|----------------------------------------------------------------------------------------------------------|
| `id`   | `string` | Код права (см. таблицу ниже).                                                                            |
| `name` | `string` | Понятное название права, локализованное на язык портала.                                                 |

Поле `id` использует грамматику кодов прав Битрикс24:

| Шаблон         | Значение                                                      |
|----------------|---------------------------------------------------------------|
| `AU`           | Все авторизованные пользователи портала.                      |
| `CR`           | Текущий пользователь.                                         |
| `U${number}`   | Конкретный пользователь по ID.                                |
| `IU${number}`  | Сотрудник по ID (с учётом экстранета).                        |
| `D${number}`   | Все сотрудники подразделения.                                 |
| `DR${number}`  | Все сотрудники подразделения, включая подчинённые.            |
| `G${number}`   | Группа пользователей (например, `G2` — все посетители).       |
| `SG${number}`  | Социальная сеть / рабочая группа.                             |

### SelectCRMParamsEntityType

```ts
type SelectCRMParamsEntityType = 'lead' | 'contact' | 'company' | 'deal' | 'quote'
```

Набор видов сущностей CRM, которые понимает `selectCRM`. Передаётся как `params.entityType` и служит ключами для `SelectCRMParamsValue` и `SelectedCRM`.

### SelectCRMParamsValue

Сопоставление ID сущностей, которые нужно заранее отметить при `multiple: true`. Читаются только запрошенные типы сущностей; лишние ключи игнорируются.

| Поле       | Тип        | Описание                                               |
|------------|------------|--------------------------------------------------------|
| `lead`     | `number[]` | ID лидов, которые нужно отметить как уже выбранные.    |
| `contact`  | `number[]` | ID контактов, которые нужно отметить как уже выбранные. |
| `company`  | `number[]` | ID компаний, которые нужно отметить как уже выбранные. |
| `deal`     | `number[]` | ID сделок, которые нужно отметить как уже выбранные.   |
| `quote`    | `number[]` | ID предложений, которые нужно отметить как уже выбранные. |

### SelectedCRMEntity

Одна строка внутри группы `SelectedCRM`.

| Поле    | Тип                           | Описание                                                                                                   |
|---------|-------------------------------|------------------------------------------------------------------------------------------------------------|
| `id`    | `string`                      | Идентификатор сущности с префиксом — см. таблицу в [`SelectedCRM`](#selectedcrm).                          |
| `type`  | `SelectCRMParamsEntityType`   | Вид сущности (`lead` / `contact` / `company` / `deal` / `quote`).                                          |
| `place` | `string`                      | Метка размещения в интерфейсе, которую использует Битрикс24 (нужна редко; справочная).                     |
| `title` | `string`                      | Отображаемое название сущности (например, название компании, сделки или полное имя контакта).              |
| `desc`  | `string`                      | Краткое описание, которое показывается рядом с названием в диалоге.                                        |
| `url`   | `string`                      | URL для открытия сущности на портале.                                                                      |

### SelectedCRM

Результат `selectCRM`. Каждое свойство — либо массив [`SelectedCRMEntity`](#selectedcrmentity) с уточнённым шаблоном `id`, либо `undefined`, если пользователь не выбрал ничего этого типа.

| Поле       | Тип                                                                   | Описание                                                                                                 |
|------------|-----------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|
| `lead`     | `(SelectedCRMEntity & { id: ``L_${number}`` })[]`                     | Выбранные лиды. Каждый `id` имеет вид `L_42`.                                                            |
| `contact`  | `(SelectedCRMEntity & { id: ``C_${number}``, image: string })[]`      | Выбранные контакты. Дополнительное поле `image` содержит URL аватара контакта.                           |
| `company`  | `(SelectedCRMEntity & { id: ``CO_${number}``, image: string })[]`     | Выбранные компании. Дополнительное поле `image` содержит URL логотипа компании.                          |
| `deal`     | `(SelectedCRMEntity & { id: ``D_${number}`` })[]`                     | Выбранные сделки. Каждый `id` имеет вид `D_17`.                                                          |
| `quote`    | `(SelectedCRMEntity & { id: ``Q_${number}`` })[]`                     | Выбранные предложения. Каждый `id` имеет вид `Q_3`.                                                      |
