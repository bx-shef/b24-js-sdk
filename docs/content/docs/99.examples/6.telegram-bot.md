## Что делает пример

Следит через `crm.item.list` за сделками с `id > lastSeenDealId` и базовой стадией `NEW`. Для каждой новой сделки загружает связанный контакт (`crm.item.get`), формирует HTML-карточку и отправляет её в чат Telegram через `grammy`. Предоставляет слэш-команды `/start` и `/status`.

## Стек

Node.js 20+, `grammy`, `node-cron`.

## Установка

```bash
pnpm add grammy node-cron
```

## Окружение

```bash
export B24_HOOK='https://your.bitrix24.com/rest/1/secret'
export TELEGRAM_BOT_TOKEN='...'   # @BotFather
export TELEGRAM_CHAT_ID='...'     # чат-получатель
```

## Запуск

```bash
npx tsx 06-telegram-bot.ts
```

## Примечания

- `lastSeenDealId` хранится в памяти — сохраняйте его, чтобы он пережил перезапуск.
- Для интерактивных действий (назначить, пометить как мусор) расширьте пример через `InlineKeyboard` из grammy.
- Экранирование HTML выполняется прямо в коде. Если вы меняете формат сообщения, оставьте `parse_mode: 'HTML'` и экранируйте строки, которые задаёт пользователь.
- Если за один такт набирается много новых сделок, замените вызов `fetchContactName` для каждой сделки одним `actions.v2.batch.make`, который получает все контакты за один обмен с сервером. Пример формы: `actions.v2.batch.make({ calls: deals.map((d) => ['crm.item.get', { entityTypeId: 3, id: d.contactId }]) })`.
