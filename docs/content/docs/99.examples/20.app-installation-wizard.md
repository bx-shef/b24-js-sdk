**Необходимые права доступа (scope)** зависят от того, что делает мастер, — как минимум `crm`, `user_brief`, `userfieldconfig`, `placement`.

Приложение Битрикс24 считается «устанавливаемым» с момента, когда пользователь принимает диалог установки, до момента, когда приложение вызывает `installFinish()`. В это окно можно создать пользовательские поля, зарегистрировать встройки, записать начальные настройки приложения — всё, что нужно приложению, прежде чем поприветствовать пользователя. Этот рецепт показывает структуру такого процесса.

## Используемые компоненты

- [`B24Button`](https://b24-ui.bx-shef.by/docs/components/button/) — действия запуска, повтора и завершения.
- [`B24Progress`](https://b24-ui.bx-shef.by/docs/components/progress/) — индикатор прогресса.
- [`ProseH1`](https://b24-ui.bx-shef.by/docs/typography/headers-and-text/#heading-1) / [`ProseP`](https://b24-ui.bx-shef.by/docs/typography/headers-and-text/#paragraph) — заголовок и текст статуса.
- [`ProsePre`](https://b24-ui.bx-shef.by/docs/typography/code/#inline-code) — вывод отладки и журнала.
- [`useConfetti`](https://b24-ui.bx-shef.by/docs/composables/use-confetti/) — заключительная анимация.

## Процесс

```ts
import { initializeB24Frame, type B24Frame } from '@bxshefby/b24jssdk'

let $b24: B24Frame

async function provision(): Promise<void> {
  // Объединяйте связанные шаги в batch, чтобы уложиться в один запрос
  await $b24.actions.v2.batch.make({
    calls: {
      addUserField: {
        method: 'userfieldconfig.add',
        params: {
          moduleId: 'crm',
          field: { ENTITY_ID: 'CRM_DEAL', FIELD_NAME: 'UF_CRM_DEAL_DEMO', USER_TYPE_ID: 'string' }
        }
      },
      bindPlacement: {
        method: 'placement.bind',
        params: { PLACEMENT: 'CRM_DEAL_LIST_MENU', HANDLER: '/embedded/menu' }
      }
    },
    options: {
      isHaltOnError: true,
      requestId: 'install:provision'
    }
  })
}

async function run() {
  $b24 = await initializeB24Frame()

  if (!$b24.isInstallMode) {
    // Уже установлено — показываем обычный интерфейс
    return
  }

  await provision()

  // Празднуйте ДО завершения: в ответ на installFinish() портал
  // перезагружает страницу, и всё после него может не выполниться.
  // празднуем через useConfetti() ...

  await $b24.installFinish()
}

run().catch(console.error)
```

Промис `installFinish()` **завершается отказом** с `SdkError` (`code: 'JSSDK_FRAME_INSTALL_ALREADY_FINISHED'`), если приложение уже не в режиме установки; защищайтесь проверкой `isInstallMode`.

::warning
**Главная мысль этого рецепта — никогда не пропускать `installFinish()`.** Приложение с мастером установки, которое не завершает установку, остаётся установленным наполовину, и портал не доставляет ему события: обработчики, привязанные через `event.bind`, не срабатывают, а встройки, привязанные через `placement.bind`, не появляются, хотя оба вызова регистрации вернули успех. Это [задокументированное поведение Битрикс24](https://apidocs.bitrix24.com/settings/app-installation/installation-finish.html#what-doesnt-work-until-installation-is-complete).

Сбой тихий и вводит в заблуждение: регистрация проходит успешно, `imbot.register` возвращает `botId`, обработчики видны при запросе списка, а события не приходят. Разработчики нередко теряют дни на nginx, туннели и TLS, прежде чем выясняют, что установка приложения так и не была завершена.

Противоположный случай тоже стоит знать — это зеркальная ошибка: **приложение только с API и без интерфейса установки** вызывать `installFinish()` *не должно*. Его установка завершается автоматически, а метод работает только внутри фрейма браузерного интерфейса, поэтому этот рецепт предназначен для приложений с экраном установки, а не для безголовых.

### «Мои обработчики не срабатывают»

Прежде чем проверять что-либо на своей стороне, спросите у портала, считает ли он приложение установленным:

```ts
const response = await $b24.actions.v2.call.make<{ INSTALLED: boolean }>({
  method: 'app.info',
  requestId: 'app-info-1'
})
console.log(response.getData()!.result.INSTALLED)
```

`INSTALLED: false` означает, что `installFinish()` так и не дошёл до портала, и отладка вашего эндпоинта не поможет, пока этого не произойдёт. `true` означает, что установка завершена и проблема где-то в другом месте.
