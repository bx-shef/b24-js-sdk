В этом разделе собраны примеры использования `@bxshefby/b24jssdk`, сгруппированные по задачам. Большинство из них — запускаемые файлы на TypeScript, которые одновременно служат **навыками для агентов**: тот же исходный код лежит в [`skills/b24jssdk-recipes/examples/`](https://github.com/bx-shef/b24-js-sdk/tree/main/skills/b24jssdk-recipes/examples), и AI-инструменты для написания кода (Claude Code, Cursor, Copilot) загружают его как авторитетный контекст по SDK. Каждый рецепт проверяется на типы в CI командой `pnpm run skills:typecheck`.

## Репозиторий

Все запускаемые примеры лежат в двух местах:

- [`skills/b24jssdk-recipes/examples/`](https://github.com/bx-shef/b24-js-sdk/tree/main/skills/b24jssdk-recipes/examples) — 12 рецептов расширенного каталога в виде скриптов на TypeScript, которые проверяются на типы в CI.
- [`bitrix24/b24sdk-examples`](https://github.com/bitrix24/b24sdk-examples) — парные витрины интерфейса (Nuxt, React) и исходные стартовые скрипты для Node и вебхука. Основные папки:
  - `js/02-nuxt-hook` — быстрый старт на Nuxt и `B24Hook`
  - `js/03-nuxt-frame` — Nuxt и `B24Frame` (помощник, клиент Pull, диалоги)
  - `js/05-node-hook` — чистый Node.js и скрипт на `B24Hook`
  - `js/04-react-frame` — React и `B24Frame`

## Участие в разработке

Не нашли нужный рецепт? Откройте issue в [bx-shef/b24-js-sdk](https://github.com/bx-shef/b24-js-sdk/issues). Pull request к рецептам, относящимся к самому SDK, отправляйте в этот репозиторий (в `skills/b24jssdk-recipes/examples/`); pull request к витринам интерфейса — в [bitrix24/b24sdk-examples](https://github.com/bitrix24/b24sdk-examples).

Делая глубокие ссылки на `b24sdk-examples`, указывайте тег (`/tree/<tag>/…` или `/blob/<tag>/…`), а не ветку (`/tree/main/…`). Тег неизменяем, поэтому ссылка всегда указывает на тот самый код, для которого писалась: она не сломается незаметно, если в том репозитории изменится структура дерева, и, что важнее, ограничивает риск для цепочки поставок, если внешний репозиторий переименуют, передадут другому владельцу или перехватят. Тег выпуска в этом репозитории пока не создан, поэтому существующие глубокие ссылки по-прежнему указывают на `main`; закрепите их за тегом, когда он появится.
