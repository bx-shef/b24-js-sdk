## Что делает пример

Охватывает все операции чтения и записи Диска Битрикс24, которые не требуют multipart: `disk.storage.getlist`, `disk.folder.getchildren` (постранично через `actions.v2.callList.make`), `disk.folder.addsubfolder`, `disk.file.get`. Включает пример `actions.v2.batch.make`, который объединяет список хранилищ и содержимое корневой папки в один обмен с сервером.

## Стек

Node.js 20+. Внешних зависимостей нет.

## Окружение

```bash
export B24_HOOK='https://your.bitrix24.com/rest/1/secret'
```

> **Нужно право доступа вебхука:** у входящего вебхука должно быть включено право **disk**.
> Портал Битрикс24 → Разработчикам → Входящие вебхуки → редактировать → отметьте **Диск (disk)**.
> Без него все вызовы API Диска возвращают `insufficient_scope` (HTTP 401).

## Запуск

```bash
npx tsx 05-disk-files.ts
```

## Примечания

- Для загрузки бинарного файла нужен `disk.folder.uploadfile` с `multipart/form-data`. SDK может сделать это через базовый транспорт `Http`, но это не прямая замена вызову `actions.v2.call.make`; такой рецепт есть в списке предложений.
- Методы Диска используют **классические** поля заглавными буквами: `ID`, `NAME`, `PARENT_ID`, `ROOT_OBJECT_ID`. API Диска в v3 нет.
- `disk.folder.getchildren` отдаёт данные постранично — всегда вызывайте его через `actions.v2.callList.make` (или `actions.v2.fetchList.make` для больших папок), а не одним `actions.v2.call.make`.
