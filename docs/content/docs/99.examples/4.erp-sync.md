## Что делает пример

Получает контакты и из Битрикс24 (через `actions.v2.fetchList.make`), и из внешней ERP (в рецепте это имитация — замените её своим клиентом). Сопоставляет их в первую очередь по ИНН (`ufCrmInn`), а при его отсутствии — по email. Создаёт недостающие записи с каждой стороны и переносит изменившиеся поля имени обратно в Битрикс24.

## Стек

Node.js 20+, `node-cron`.

## Установка

```bash
pnpm add node-cron
```

## Окружение

```bash
export B24_HOOK='https://your.bitrix24.com/rest/1/secret'
```

## Запуск

```bash
npx tsx 04-erp-sync.ts
```

## Примечания

- Функции стороны ERP (`fetchErpContacts`, `createErpContact`, `updateErpContact`) — заглушки. Подставьте свой клиент (OData 1С, REST и т. д.).
- Ключ сопоставления — `ufCrmInn`; подставьте имя поля, которое используется в пространстве имён ваших пользовательских полей.
- Для тысяч контактов узким местом становится цикл с `await createBitrixContact` для каждой строки. Замените его на `actions.v2.batchByChunk.make({ calls: erpContacts.map((e) => ['crm.item.add', { entityTypeId: 3, fields: ... }]), options: { isHaltOnError: false } })`; базовую форму `batch.make` см. в [рецепте 5 (файлы Диска)](/docs/examples/disk-files/), а подробности `batchByChunk.make` — в навыке `b24jssdk-rest`.
