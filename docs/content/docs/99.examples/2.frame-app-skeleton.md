## Цель

Один компонент Vue 3, который показывает четыре вещи, нужные каждому iframe-приложению Битрикс24: выполнить рукопожатие через postMessage, задать заголовок родительского окна, сохранить часть состояния между перезагрузками через настройки приложения и открыть другую страницу портала в слайдере.

## Стек и требования

- Vue 3 + Vite (или Nuxt 3 с `@bxshefby/b24jssdk-nuxt`)
- `@bxshefby/b24jssdk@^1.0.0`
- Страница должна отдаваться с URL, зарегистрированного как обработчик встройки (placement) в карточке приложения Битрикс24. Вне iframe `initializeB24Frame()` завершается отказом.

::caution
Этот каркас рассчитан на **уже работающее** приложение, а не на устанавливаемое. Если `$b24.isInstallMode`{lang="ts-type"} равен `true`{lang="ts-type"}, приложение должно завершить установку вызовом `installFinish()`{lang="ts-type"}: пока этого не произошло, портал **не доставляет ему никаких событий**, обработчики ботов и обработчики `event.bind` не срабатывают, и ничего не сообщит об этом явной ошибкой. См. [рецепт «Мастер установки приложения»](/docs/examples/app-installation-wizard/).
::

```bash
pnpm add @bxshefby/b24jssdk
```

## Полный пример

`src/components/AppShell.vue`:

```vue
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue'
import {
  initializeB24Frame,
  type B24Frame,
  LoggerFactory
} from '@bxshefby/b24jssdk'

const logger = LoggerFactory.createForBrowser('AppShell', import.meta.env.DEV)
const ready = ref(false)
const userTheme = ref<'light' | 'dark'>('light')
const portalDomain = ref('')
let $b24: B24Frame | null = null

onMounted(async () => {
  try {
    // `keepAuthFresh` is only needed if you use the token outside the SDK —
    // see the note under this snippet.
    $b24 = await initializeB24Frame()
  }
  catch (error) {
    logger.error('initializeB24Frame failed', error)
    return
  }

  $b24.parent.setTitle('My Bitrix24 App') // sets the in-page #pagetitle, not the browser tab
  // Auto-resize the iframe to fit its content; call again when content height
  // changes (e.g. after a network response renders).
  await $b24.parent.resizeWindowAuto()

  // Read persisted preferences. Returns `null` if nothing was set yet.
  const stored = $b24.options.appGet('theme') as 'light' | 'dark' | null
  if (stored) userTheme.value = stored

  const appInfo = await $b24.actions.v2.call.make({ method: 'app.info' })
  portalDomain.value = appInfo.getData().result.DOMAIN ?? ''

  ready.value = true
})

onBeforeUnmount(() => {
  $b24 = null
})

async function setTheme(value: 'light' | 'dark') {
  userTheme.value = value
  // App-scoped option: persisted on the portal under the app, not the user.
  await $b24?.options.appSet('theme', value)
}

async function openCrmDeals() {
  if (!$b24) return
  const url = new URL('/crm/deal/list/', `https://${portalDomain.value}`)
  await $b24.slider.openPath(url, 1200)
}

function close() {
  // Not awaited: the portal answers this one only sometimes (#328).
  $b24?.parent.closeApplication().catch(() => {})
}
</script>

<template>
  <section v-if="ready" class="app-shell" :data-theme="userTheme">
    <header>
      <h1>Hello from {{ portalDomain }}</h1>
    </header>

    <main>
      <button @click="setTheme(userTheme === 'light' ? 'dark' : 'light')">
        Switch theme (current: {{ userTheme }})
      </button>
      <button @click="openCrmDeals">
        Open deals in slider
      </button>
    </main>

    <footer>
      <button @click="close">Close app</button>
    </footer>
  </section>
  <p v-else>Loading…</p>
</template>
```

`src/main.ts`:

<!-- @check-ignore: vue .vue module import — .vue files are not in tsconfig -->
```ts
import { createApp } from 'vue'
import AppShell from './components/AppShell.vue'

createApp(AppShell).mount('#app')
```

## Запуск

```bash
# 1. Local dev server (Vite)
pnpm dev
# → http://localhost:5173/ — running this URL directly will reject:
#   initializeB24Frame() needs a parent Bitrix24 window.

# 2. Expose the dev server (ngrok / cloudflared / your tunnel of choice)
ngrok http 5173
# → grab the https URL.

# 3. In Bitrix24: Applications → Developer resources → Local app →
#    point the placement handler URL at the tunnel URL and Save.

# 4. Open the placement inside Bitrix24.
```

После загрузки iframe вы увидите: заголовок родительского окна станет «My Bitrix24 App», iframe подстроится под размер содержимого, а в теле страницы появятся `Hello from <your-portal>.bitrix24.com` и две кнопки. Переключение темы сохраняется между перезагрузками (значение хранится на портале в настройках приложения, а не в `localStorage`). Нажатие «Open deals in slider» открывает `/crm/deal/list/` того же портала в слайдере в стиле Битрикс24.

## Как это работает

- `initializeB24Frame()` — единственный верный способ создать `B24Frame`. Он дедуплицирует одновременные вызовы, разбирает параметры рукопожатия с порталом из `window.name` и ждёт, пока родительское окно подтвердит получение данных авторизации.
- Токен обновляется за вас **на пути запроса**: просроченный токен обновляется перед вызовом и ещё раз при ответе `401`. Этот каркас вызывает `app.info` через `$b24`, поэтому он под защитой. Приложение, которое вместо этого читает `$b24.auth.getAuthData()` и передаёт токен своему бэкенду, не делает вызовов через `$b24` вообще, поэтому токен никто не обновляет, и неактивная вкладка его теряет: такому приложению нужен `initializeB24Frame({ keepAuthFresh: true })`, переданный при **первой** инициализации. См. [Сохранение токена актуальным](/docs/entry-points/frame-initialize-b24-frame/#сохранение-токена-актуальным).
- `parent.setTitle()` и `parent.resizeWindowAuto()` пересекают границу iframe через `postMessage`. Оба вызова идемпотентны — вызывайте их при каждом изменении разметки.
- `options.appGet()` синхронный, потому что значения загружаются один раз при рукопожатии. `options.appSet()` асинхронный, потому что обращается к серверу.
- `slider.openPath(url, width)` принимает экземпляр `URL` (не строку) и возвращает `Promise<StatusClose>`, который завершается, когда пользователь закрывает слайдер. Политика CSP портала разрешает открывать только URL на домене того же портала.

## Ограничения

- Компонент должен монтироваться **внутри** iframe Битрикс24; запуск отдельно (например, в Storybook) сразу завершается ошибкой, потому что родительского окна нет. Если нужен мягкий запасной вариант, проверяйте `window.parent === window`.
- `$b24.options.appSet()` записывает одну настройку за раз. Несколько записей подряд в одном рендере допустимы (SDK их сериализует), но каждый вызов — отдельное обращение к серверу.
- `parent.closeApplication()` закрывает слайдер приложения, только если встройка поддерживает закрытие. Встроенные места (виджеты боковой панели) запрос игнорируют.
- **Не используйте для него `await`**: в некоторых сборках портал не отвечает, и ожидание не завершится никогда ([#328](https://github.com/bitrix24/b24jssdk/issues/328)). Очистку выполняйте до вызова, как в `close()` выше.
- Настройки уровня приложения видны всем пользователям приложения на портале. Для персональных предпочтений используйте `userGet` / `userSet`.
