# @bitrix24/b24jssdk

JS SDK для работы с REST API Битрикс24 в локальных и тиражных приложениях или через вебхуки

Пакет поставляется в сборках **ESM**, **CommonJS** и **UMD**. Рекомендуемая точка входа — ESM (`import { B24Hook } from '@bitrix24/b24jssdk'`); CommonJS тоже поддерживается (`const { B24Hook } = require('@bitrix24/b24jssdk')`), а UMD-сборка предназначена для подключения через `<script>` в браузере.

Подробности — в [документации](https://bitrix24.github.io/b24jssdk/)
