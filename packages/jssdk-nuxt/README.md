# @bxshefby/b24jssdk-nuxt

JS SDK для REST API Битрикс24 в Nuxt

## Быстрая установка

Подключите модуль к приложению на Nuxt одной командой:

```bash
npx nuxi module add @bxshefby/b24jssdk-nuxt
```

Это всё! Теперь `@bxshefby/b24jssdk-nuxt` можно использовать в приложении на Nuxt

Подробности — в [документации](https://b24-js-sdk.bx-shef.by/docs/getting-started/installation/nuxt/)
